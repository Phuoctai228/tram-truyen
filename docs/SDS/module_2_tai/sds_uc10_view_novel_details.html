2. View Novel Details (UC-10)

b. Class Specifications

NovelController Class

No Method Description
01 novelDetailsBySlug - Input: slug: String, authentication: Authentication, model: Model.
- Output: String (View name "novel/details").
- Internal Method Processing: Handles GET /truyen/{slug} request. Retrieves the public novel by slug via novelService.getPublicNovelBySlug(slug) and fetches its published table of contents via chapterService.getPublicChapters(novelId). If the user is authenticated, checks bookshelf membership (isNovelInBookshelf), reading history existence (hasReadAnyChapter), and latest read chapter bookmark (getLastReadChapter). Also fetches total favorites (countNovelFavorites) and related works by the same author (getNovelsBySameAuthor), binds all attributes to the Model, and renders "novel/details".

NovelService Interface

No Method Description
01 getPublicNovelBySlug - Input: slug: String.
- Output: Novel.
- Internal Method Processing: Retrieves an active, non-archived novel matching the given URL slug or throws ResourceNotFoundException if not found.
02 getNovelsBySameAuthor - Input: author: String, currentNovelId: Integer.
- Output: List<Novel>.
- Internal Method Processing: Retrieves up to 5 public novels written by the same author (excluding the current novel) ordered by views descending.

NovelServiceImpl Class

No Method Description
01 getPublicNovelBySlug - Input: slug: String.
- Output: Novel.
- Internal Method Processing: Validates that slug is non-blank and queries novelRepository.findBySlugAndIsDeletedFalseAndStatusNot(slug, "ARCHIVED"). Throws ResourceNotFoundException if the novel does not exist, is soft-deleted, or is archived.
02 getNovelsBySameAuthor - Input: author: String, currentNovelId: Integer.
- Output: List<Novel>.
- Internal Method Processing: Queries novelRepository.findTop5ByAuthorIgnoreCaseAndIdNotAndIsDeletedFalseOrderByViewsDesc() and filters out archived novels to display related titles by the same author.

ChapterService Interface

No Method Description
01 getPublicChapters - Input: novelId: Integer.
- Output: List<Chapter>.
- Internal Method Processing: Retrieves all publicly published chapters belonging to the specified novel ordered by chapter number ascending.

ChapterServiceImpl Class

No Method Description
01 getPublicChapters - Input: novelId: Integer.
- Output: List<Chapter>.
- Internal Method Processing: Verifies that the parent novel is public via novelRepository.findByIdAndIsDeletedFalseAndStatusNot(novelId, "ARCHIVED"), then calls chapterRepository.findAllByNovelIdAndIsDeletedFalseAndStatusInOrderByChapterNumberAsc() with public statuses (PUBLISHED_REGULAR, PUBLISHED_VIP, PUBLISHED).

BookshelfService Interface

No Method Description
01 isNovelInBookshelf - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Checks whether the authenticated user has already saved the novel in their personal bookshelf.
02 hasReadAnyChapter - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Checks whether the user has read at least one chapter of the novel.
03 countNovelFavorites - Input: novelId: Integer.
- Output: long.
- Internal Method Processing: Returns the total number of readers who bookmarked the novel in their bookshelf.
04 getLastReadChapter - Input: email: String, novelId: Integer.
- Output: Optional<Chapter>.
- Internal Method Processing: Retrieves the most recently read chapter of the novel for the "Continue Reading" button.

BookshelfServiceImpl Class

No Method Description
01 isNovelInBookshelf - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Looks up the User by email and the Novel by ID, then calls bookshelfRepository.existsByUserAndNovel(user, novel). Returns false if not found.
02 hasReadAnyChapter - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Looks up the User and Novel entities and checks if userChapterActivityRepository.countByUserAndChapter_NovelAndIsReadTrue(user, novel) > 0.
03 countNovelFavorites - Input: novelId: Integer.
- Output: long.
- Internal Method Processing: Delegates to bookshelfRepository.countByNovelId(novelId) to return total favorites.
04 getLastReadChapter - Input: email: String, novelId: Integer.
- Output: Optional<Chapter>.
- Internal Method Processing: Queries userChapterActivityRepository.findFirstByUserAndChapter_NovelAndIsReadTrueOrderByReadAtDescChapter_ChapterNumberDesc(user, novel) and extracts the non-deleted Chapter entity.

NovelRepository Interface

No Method Description
01 findBySlugAndIsDeletedFalseAndStatusNot - Input: slug: String, status: String.
- Output: Optional<Novel>.
- Internal Method Processing: Finds a non-deleted novel by slug whose status is not ARCHIVED.
02 findByIdAndIsDeletedFalseAndStatusNot - Input: id: Integer, status: String.
- Output: Optional<Novel>.
- Internal Method Processing: Finds a non-deleted novel by ID whose status is not ARCHIVED.
03 findByIdAndIsDeletedFalse - Input: id: Integer.
- Output: Optional<Novel>.
- Internal Method Processing: Finds a non-deleted novel by primary key ID.
04 findTop5ByAuthorIgnoreCaseAndIdNotAndIsDeletedFalseOrderByViewsDesc - Input: author: String, id: Integer.
- Output: List<Novel>.
- Internal Method Processing: Finds up to 5 other non-deleted novels by the same author (case-insensitive) ordered by views descending.

ChapterRepository Interface

No Method Description
01 findAllByNovelIdAndIsDeletedFalseAndStatusInOrderByChapterNumberAsc - Input: novelId: Integer, statuses: List<String>.
- Output: List<Chapter>.
- Internal Method Processing: Retrieves all non-deleted published chapters of the specified novel ordered by chapter_number ascending.

BookshelfRepository Interface

No Method Description

UserRepository Interface

UserChapterActivityRepository Interface

No Method Description
01 countByUserAndChapter_NovelAndIsReadTrue - Input: user: User, novel: Novel.
- Output: long.
- Internal Method Processing: Counts how many chapters of the specified novel have been marked as read (is_read = TRUE) by the user.
02 findFirstByUserAndChapter_NovelAndIsReadTrueOrderByReadAtDescChapter_ChapterNumberDesc - Input: user: User, novel: Novel.
- Output: Optional<UserChapterActivity>.
- Internal Method Processing: Retrieves the user's most recent read chapter activity for the novel ordered by read_at descending and chapter_number descending.

d. Database Queries

1. Retrieve public novel by slug

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE slug = ? AND is_deleted = FALSE AND status <> 'ARCHIVED';

2. Verify public novel by ID

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE id = ? AND is_deleted = FALSE AND status <> 'ARCHIVED';

3. Retrieve all published chapters of the novel

SELECT id, novel_id, chapter_number, title, price, status, views, created_at, updated_at FROM chapters WHERE novel_id = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED') ORDER BY chapter_number ASC;

4. Retrieve authenticated user by email

SELECT id, email, password, full_name, avatar_url, wallet_balance, auth_provider, status, created_at, updated_at FROM users WHERE email = ?;

5. Check if novel is in user's bookshelf

SELECT EXISTS ( SELECT 1 FROM bookshelves WHERE user_id = ? AND novel_id = ? );

6. Count read chapters of the novel for the user

SELECT COUNT(uca.id) FROM user_chapter_activities uca INNER JOIN chapters c ON uca.chapter_id = c.id WHERE uca.user_id = ? AND c.novel_id = ? AND uca.is_read = TRUE;

7. Retrieve latest read chapter activity for "Continue Reading"

SELECT uca.id, uca.user_id, uca.chapter_id, uca.is_read, uca.read_at, c.chapter_number, c.title, c.status FROM user_chapter_activities uca INNER JOIN chapters c ON uca.chapter_id = c.id WHERE uca.user_id = ? AND c.novel_id = ? AND uca.is_read = TRUE ORDER BY uca.read_at DESC, c.chapter_number DESC LIMIT 1;

8. Count total bookshelf favorites for the novel

SELECT COUNT(id) FROM bookshelves WHERE novel_id = ?;

9. Retrieve top 5 novels by the same author

SELECT id, title, slug, author, summary, cover_url, status, views, average_rating, rating_count FROM novels WHERE LOWER(author) = LOWER(?) AND id <> ? AND is_deleted = FALSE ORDER BY views DESC LIMIT 5;
