6. Add Novel to Bookshelf (UC-20)

b. Class Specifications

BookshelfController Class

No Method Description
01 addNovelToBookshelf - Input: novelId: Integer, source: String, authentication: Authentication, redirectAttributes: RedirectAttributes.
- Output: String (Redirect URL).
- Internal Method Processing: Handles POST /user/bookshelf/{novelId} request. Checks whether the user is authenticated; if not, redirects to /login. Invokes bookshelfService.addNovelToBookshelf(email, novelId), attaches a success or error flash message to redirectAttributes, and redirects back to the source page (e.g., /novel/{novelId} or homepage).
02 toggleBookshelfAjax - Input: novelId: Integer, authentication: Authentication.
- Output: ResponseEntity<?>.
- Internal Method Processing: Handles POST /api/user/bookshelf/{novelId}/toggle AJAX request. Validates authentication, checks if the novel is already in the bookshelf via bookshelfService.isNovelInBookshelf(email, novelId), and if not present, calls bookshelfService.addNovelToBookshelf(email, novelId) and returns a JSON response with inBookshelf: true.

BookshelfService Interface

No Method Description
01 addNovelToBookshelf - Input: email: String, novelId: Integer.
- Output: void.
- Internal Method Processing: Adds the specified novel to the authenticated member's personal bookshelf.
02 isNovelInBookshelf - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Checks whether the specified novel already exists in the member's bookshelf.

BookshelfServiceImpl Class

No Method Description
01 addNovelToBookshelf - Input: email: String, novelId: Integer.
- Output: void.
- Internal Method Processing: Retrieves the User by email via userRepository.findByEmail(email) and the active Novel by ID via novelRepository.findByIdAndIsDeletedFalse(novelId) (throwing ResourceNotFoundException if not found). Checks for duplicate bookmarking via bookshelfRepository.existsByUserAndNovel(user, novel) and throws DuplicateResourceException if already present. Otherwise, instantiates a new Bookshelf(user, novel) entity and persists it via bookshelfRepository.save(bookshelf).
02 isNovelInBookshelf - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Retrieves the User and Novel entities and returns the boolean result of bookshelfRepository.existsByUserAndNovel(user, novel).

BookshelfRepository Interface

No Method Description
01 existsByUserAndNovel - Input: user: User, novel: Novel.
- Output: boolean.
- Internal Method Processing: Checks whether a bookshelf record already exists for the specified user and novel pair.
02 save - Input: bookshelf: Bookshelf.
- Output: Bookshelf.
- Internal Method Processing: Inserts the new Bookshelf record into the bookshelves table.

UserRepository Interface

No Method Description
01 findByEmail - Input: email: String.
- Output: Optional<User>.
- Internal Method Processing: Retrieves the authenticated member's User entity by email address.

NovelRepository Interface

No Method Description
01 findByIdAndIsDeletedFalse - Input: id: Integer.
- Output: Optional<Novel>.
- Internal Method Processing: Finds the non-deleted Novel entity by its primary key ID.

d. Database Queries

1. Retrieve authenticated user by email

SELECT id, email, full_name, status FROM users WHERE email = ?;

2. Retrieve active novel by ID

SELECT id, title, slug, author, status, is_deleted FROM novels WHERE id = ? AND is_deleted = FALSE;

3. Check if novel already exists in user's bookshelf

SELECT EXISTS ( SELECT 1 FROM bookshelves WHERE user_id = ? AND novel_id = ? );

4. Insert new bookshelf entry

INSERT INTO bookshelves (user_id, novel_id, added_at) VALUES (?, ?, CURRENT_TIMESTAMP) RETURNING id, user_id, novel_id, added_at;
