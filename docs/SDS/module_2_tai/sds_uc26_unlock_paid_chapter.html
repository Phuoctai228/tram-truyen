8. Unlock Paid Chapter (UC-26)

b. Class Specifications

NovelController Class

No Method Description
01 unlockChapter - Input: slug: String, chapterNumber: Integer, autoUnlockNext: Boolean, authentication: Authentication, request: HttpServletRequest, redirectAttributes: RedirectAttributes.
- Output: Object (ResponseEntity<UnlockResultDTO> for AJAX or redirect URL String).
- Internal Method Processing: Handles POST /truyen/{slug}/chuong-{chapterNumber}/unlock request. Verifies user authentication; if unauthenticated, returns HTTP 401 (AJAX) or redirects to /login. Resolves the public novel via novelService.getPublicNovelBySlug(slug) and target chapter via chapterService.getPublicChapter(novelId, chapterNumber). Invokes chapterUnlockService.unlockChapter(email, chapterId, autoUnlockNext) and returns the result as JSON or redirects back to the unlocked chapter page.

ChapterUnlockServiceImpl Class

No Method Description
01 isChapterUnlocked - Input: email: String, chapterId: Integer.
- Output: boolean.
- Internal Method Processing: Checks if the chapter is free, if the user has a privileged role (ROLE_ADMIN/ROLE_STAFF), or if an unlocked UserChapterActivity record exists.
02 unlockChapter - Input: email: String, chapterId: Integer, autoUnlockNext: Boolean.
- Output: UnlockResultDTO.
- Internal Method Processing: Fetches the Chapter by ID and validates eligibility via validateChapterEligibility(chapter). Acquires a pessimistic write lock on the User via userRepository.findByEmailWithLock(email). If the user is privileged, already unlocked the chapter, or the chapter is free, returns a 0-Coin UnlockResultDTO. Otherwise, deducts the chapter price via walletService.deductCoins(lockedUser, price, "UNLOCK_CHAPTER", chapterId, description), records the unlock via markChapterUnlocked(), and returns the completed UnlockResultDTO.
03 validateChapterEligibility - Input: chapter: Chapter.
- Output: void.
- Internal Method Processing: Ensures neither the chapter nor its novel is soft-deleted, the novel is not ARCHIVED, and the chapter status is not DRAFT or LOCKED; otherwise throws ChapterNotPurchasableException.
04 buildTransactionDescription - Input: chapter: Chapter.
- Output: String.
- Internal Method Processing: Formats a human-readable ledger description containing the chapter number, chapter title, and novel title.
05 markChapterUnlocked - Input: user: User, chapter: Chapter, price: int, existingOpt: Optional<UserChapterActivity>.
- Output: void.
- Internal Method Processing: Creates or updates the UserChapterActivity entity with isUnlocked = true, pricePaid = price, and unlockedAt = LocalDateTime.now(), then saves it via userChapterActivityRepository.save(activity).

- Output: void.
- Internal Method Processing: Deducts the specified Coin amount from the user's wallet balance and records a ledger transaction.

WalletServiceImpl Class

No Method Description
01 deductCoins - Input: user: User, amount: int, transactionType: String, referenceId: Integer, description: String.
- Output: void.
- Internal Method Processing: Locks the user row using userRepository.findByIdWithLock(userId). Checks if walletBalance >= amount; if insufficient, throws InsufficientBalanceException. Subtracts amount from walletBalance, saves the updated User via userRepository.save(lockedUser), creates a Transaction record with amount = -price and type = "UNLOCK_CHAPTER", and persists it via transactionRepository.save(tx).

d. Database Queries

1. Retrieve public novel by slug

SELECT id, title, slug, status, is_deleted FROM novels WHERE slug = ? AND is_deleted = FALSE AND status <> 'ARCHIVED';

2. Retrieve published chapter by novel ID and chapter number

SELECT id, novel_id, chapter_number, title, price, status, is_deleted FROM chapters WHERE novel_id = ? AND chapter_number = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED');

3. Retrieve chapter by ID for eligibility check

SELECT id, novel_id, chapter_number, title, price, status, is_deleted FROM chapters WHERE id = ?;

4. Lock user row by email for concurrent purchase safety

SELECT id, email, full_name, wallet_balance, status FROM users WHERE email = ? FOR UPDATE;

5. Check existing user chapter activity

SELECT id, user_id, chapter_id, is_read, read_at, is_unlocked, price_paid, unlocked_at FROM user_chapter_activities WHERE user_id = ? AND chapter_id = ?;

6. Lock user row by ID before wallet deduction

SELECT id, email, full_name, wallet_balance, status FROM users WHERE id = ? FOR UPDATE;

7. Deduct Coin price from user wallet balance

UPDATE users SET wallet_balance = ?, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

8. Insert UNLOCK_CHAPTER transaction into wallet ledger

INSERT INTO transactions (user_id, amount, balance_after, type, reference_id, description, created_at) VALUES (?, ?, ?, 'UNLOCK_CHAPTER', ?, ?, CURRENT_TIMESTAMP) RETURNING id;

9. Record permanent VIP chapter unlock for the user

INSERT INTO user_chapter_activities (user_id, chapter_id, is_unlocked, price_paid, unlocked_at) VALUES (?, ?, TRUE, ?, CURRENT_TIMESTAMP) ON CONFLICT (user_id, chapter_id) DO UPDATE SET is_unlocked = TRUE, price_paid = EXCLUDED.price_paid, unlocked_at = CURRENT_TIMESTAMP;
