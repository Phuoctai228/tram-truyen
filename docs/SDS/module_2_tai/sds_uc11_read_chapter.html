3. Read Chapter (UC-11)

b. Class Specifications

NovelController Class

No Method Description
01 readChapterBySlug - Input: slug: String, chapterNumber: Integer, authentication: Authentication, request: HttpServletRequest, model: Model.
- Output: String (View name "novel/reading").
- Internal Method Processing: Handles GET /truyen/{slug}/chuong-{chapterNumber} request. Fetches the public novel via novelService.getPublicNovelBySlug(slug) and target chapter via chapterService.getPublicChapter(novelId, chapterNumber). Checks HTTP session attribute VIEWED_CHAPTER_IDS to deduplicate views per session and calls chapterService.recordView(novelId, chapterId) on first visit. Invokes chapterAccessService.checkAccess(novel, chapter, authentication) to resolve VIP lock status and readable paragraphs. Fetches the full published chapter list to calculate prevChapterNumber and nextChapterNumber, populates the Model, and returns "novel/reading".

ChapterService Interface

No Method Description

- Output: Chapter.
- Internal Method Processing: Retrieves a published chapter by novel ID and chapter number.
02 getPublicChapters - Input: novelId: Integer.

- Output: void.

ChapterServiceImpl Class

No Method Description
01 getPublicChapter - Input: novelId: Integer, chapterNumber: Integer.
- Output: Chapter.
- Internal Method Processing: Verifies the novel is public via novelRepository.findByIdAndIsDeletedFalseAndStatusNot(novelId, "ARCHIVED"), queries chapterRepository.findByNovelIdAndChapterNumberAndIsDeletedFalseAndStatusIn(), sanitizes the HTML content, and returns the Chapter entity (or throws ResourceNotFoundException).
02 getPublicChapters - Input: novelId: Integer.
- Output: List<Chapter>.
- Internal Method Processing: Queries chapterRepository.findAllByNovelIdAndIsDeletedFalseAndStatusInOrderByChapterNumberAsc(novelId, PUBLIC_STATUSES) to return the ordered list of published chapters.
03 recordView - Input: novelId: Integer, chapterId: Integer.
- Output: void.
- Internal Method Processing: Fetches the Chapter by chapterId, increments chapter.views by 1, and saves it via chapterRepository.save(). Then fetches the parent Novel by novelId, increments novel.views by 1, and saves it via novelRepository.save().

ChapterAccessService Interface

No Method Description
01 checkAccess - Input: novel: Novel, chapter: Chapter, authentication: Authentication.
- Output: ChapterAccessDTO.
- Internal Method Processing: Evaluates whether the visitor can read the full chapter or only a locked VIP preview.

ChapterAccessServiceImpl Class

No Method Description
01 checkAccess - Input: novel: Novel, chapter: Chapter, authentication: Authentication.
- Output: ChapterAccessDTO.
- Internal Method Processing: Checks authentication state. If authenticated, checks privileged roles via chapterAccessPolicy.isPrivileged(), loads the User via userRepository.findByEmail(), and checks if the user has already unlocked the chapter via userChapterActivityRepository.findByUserAndChapter(). Resolves ChapterAccessStatus via chapterAccessPolicy.resolve(). If readable, splits full content via chapterPreviewBuilder.splitParagraphs(); otherwise generates a truncated teaser via chapterPreviewBuilder.buildPreview(). Returns ChapterAccessDTO.

ChapterAccessPolicy Class

No Method Description
01 isPaid - Input: chapter: Chapter.
- Output: boolean.
- Internal Method Processing: Returns true if chapter.status is PUBLISHED_VIP and chapter.price > 0.
02 isPrivileged - Input: authorities: Collection<GrantedAuthority> (or role names).
- Output: boolean.
- Internal Method Processing: Returns true if the user holds ROLE_ADMIN or ROLE_STAFF.
03 resolve - Input: chapter: Chapter, loggedIn: boolean, privileged: boolean, alreadyUnlocked: boolean, walletBalance: int.
- Output: ChapterAccessStatus.
- Internal Method Processing: Evaluates chapter access state in priority order: FREE (if not paid), LOGIN_REQUIRED (if guest), STAFF_BYPASS (if Staff/Admin), UNLOCKED (if already purchased), PURCHASABLE (if walletBalance >= price), or INSUFFICIENT_BALANCE.

ChapterPreviewBuilder Class

No Method Description
01 splitParagraphs - Input: content: String.
- Output: List<String>.
- Internal Method Processing: Splits the full chapter text by line breaks into non-blank paragraphs for readable chapters.
02 buildPreview - Input: content: String.
- Output: List<String>.
- Internal Method Processing: Extracts at most 2 paragraphs (capped at 500 characters) to display as a preview teaser when a VIP chapter is locked.

d. Database Queries

1. Retrieve public novel by slug

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, views, average_rating, rating_count FROM novels WHERE slug = ? AND is_deleted = FALSE AND status <> 'ARCHIVED';

2. Retrieve published chapter by novel ID and chapter number

SELECT id, novel_id, chapter_number, title, content, price, auto_unlock_at, views, status, is_deleted, created_at, updated_at FROM chapters WHERE novel_id = ? AND chapter_number = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED');

3. Increment chapter view count

UPDATE chapters SET views = views + 1, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

4. Increment novel cumulative view count

UPDATE novels SET views = views + 1, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

5. Retrieve authenticated user by email

SELECT id, email, full_name, wallet_balance, status FROM users WHERE email = ?;

6. Check user's unlock and reading activity for the chapter

SELECT id, user_id, chapter_id, is_read, read_at, is_unlocked, price_paid, unlocked_at FROM user_chapter_activities WHERE user_id = ? AND chapter_id = ?;

7. Retrieve all published chapters for previous/next chapter navigation

SELECT id, novel_id, chapter_number, title, price, status FROM chapters WHERE novel_id = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED') ORDER BY chapter_number ASC;
