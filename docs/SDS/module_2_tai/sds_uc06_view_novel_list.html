1. View Novel List (UC-06)

b. Class Specifications

HomeController Class

No Method Description
01 home - Input: authentication: Authentication, model: Model.
- Output: String (View name "home/index").
- Internal Method Processing: Handles GET / request to display the public novel list on the homepage. Invokes homeService.getHomePageData() to retrieve categorized novel lists (recently updated, hot/most-viewed, completed, recommended, and newly created novels). Extracts the top 5 hot novels for the hero banner, checks whether the featured hero novel is already in the authenticated user's bookshelf via bookshelfService.isNovelInBookshelf(), populates the Spring MVC Model, and returns the "home/index" view.

HomeService Interface

No Method Description
01 getHomePageData - Input: None.
- Output: HomePageDTO.
- Internal Method Processing: Defines the service contract to aggregate and return all public novel lists displayed on the homepage.

HomeServiceImpl Class

No Method Description
01 getHomePageData - Input: None.
- Output: HomePageDTO.
- Internal Method Processing: Queries NovelRepository for five homepage sections: top 12 recently updated novels, top 10 hot novels by view count, top 12 completed novels, top 12 recommended novels (having at least one published chapter, ordered by average rating and views), and top 12 newly added novels. Filters out archived novels using publicNovels(), transforms each Novel entity into a NovelSummaryDTO via mapToSummaryDTO(), and builds the aggregated HomePageDTO object.
02 mapToSummaryDTO - Input: novel: Novel, includeChapters: boolean.
- Output: NovelSummaryDTO.
- Internal Method Processing: Queries bookshelfRepository.countByNovelId() to get the total favorite count for the novel. If includeChapters is true, queries chapterRepository.findTop3ByNovelIdAndIsDeletedFalseAndStatusInOrderByChapterNumberDesc() to fetch up to 3 latest published chapters and maps them to LatestChapterDTO with formatted relative timestamps. Constructs and returns a NovelSummaryDTO.
03 publicNovels - Input: novels: List<Novel>.
- Output: List<Novel>.
- Internal Method Processing: Filters the input list of novels to exclude any novel whose status is "ARCHIVED", ensuring only publicly visible novels are returned.

BookshelfService Interface

No Method Description
01 isNovelInBookshelf - Input: email: String, novelId: Integer.
- Output: boolean.
- Internal Method Processing: Checks whether the specified novel (featured in the homepage hero banner) is already saved in the authenticated user's personal bookshelf.

NovelRepository Interface

No Method Description
01 findTop12ByIsDeletedFalseOrderByUpdatedAtDesc - Input: None.
- Output: List<Novel>.
- Internal Method Processing: Retrieves the top 12 non-deleted novels ordered by updated_at descending for the "Recently Updated" section.
02 findTop10ByIsDeletedFalseOrderByViewsDesc - Input: None.
- Output: List<Novel>.
- Internal Method Processing: Retrieves the top 10 non-deleted novels ordered by total views descending for the "Hot Novels" ranking and hero banner.
03 findTop12ByIsDeletedFalseAndStatusOrderByUpdatedAtDesc - Input: status: String ("COMPLETED").
- Output: List<Novel>.
- Internal Method Processing: Retrieves the top 12 non-deleted novels matching the given status (COMPLETED) ordered by updated_at descending.
04 findTopRecommendedNovels - Input: publicStatuses: Collection<String>, pageable: Pageable.
- Output: List<Novel>.
- Internal Method Processing: Executes a custom JPQL query to fetch non-deleted, non-archived novels that have at least one published chapter, ordered by average_rating descending and views descending.
05 findTop12ByIsDeletedFalseOrderByCreatedAtDesc - Input: None.
- Output: List<Novel>.
- Internal Method Processing: Retrieves the top 12 non-deleted novels ordered by created_at descending for the "New Novels" section.

ChapterRepository Interface

No Method Description
01 findTop3ByNovelIdAndIsDeletedFalseAndStatusInOrderByChapterNumberDesc - Input: novelId: Integer, statuses: List<String>.
- Output: List<Chapter>.
- Internal Method Processing: Retrieves up to 3 latest non-deleted published chapters (PUBLISHED_REGULAR, PUBLISHED_VIP) for a given novel ordered by chapter_number descending.

BookshelfRepository Interface

No Method Description
01 countByNovelId - Input: novelId: Integer.
- Output: long.
- Internal Method Processing: Counts the total number of users who have saved the specified novel in their personal bookshelf.

d. Database Queries

1. Retrieve top 12 recently updated novels

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE is_deleted = FALSE ORDER BY updated_at DESC LIMIT 12;

2. Retrieve top 10 hot novels by view count

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE is_deleted = FALSE ORDER BY views DESC LIMIT 10;

3. Retrieve top 12 completed novels

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE is_deleted = FALSE AND status = ? ORDER BY updated_at DESC LIMIT 12;

4. Retrieve top 12 recommended public novels

SELECT n.id, n.title, n.slug, n.author, n.summary, n.cover_url, n.status, n.is_deleted, n.uploader_id, n.views, n.average_rating, n.rating_count, n.created_at, n.updated_at FROM novels n WHERE n.is_deleted = FALSE AND n.status <> 'ARCHIVED' AND EXISTS ( SELECT 1 FROM chapters c WHERE c.novel_id = n.id AND c.is_deleted = FALSE AND c.status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED') ) ORDER BY n.average_rating DESC, n.views DESC LIMIT 12 OFFSET 0;

5. Retrieve top 12 newly created novels

SELECT id, title, slug, author, summary, cover_url, status, is_deleted, uploader_id, views, average_rating, rating_count, created_at, updated_at FROM novels WHERE is_deleted = FALSE ORDER BY created_at DESC LIMIT 12;

6. Count total bookshelf favorites for a novel

SELECT COUNT(id) FROM bookshelves WHERE novel_id = ?;

7. Retrieve top 3 latest published chapters per novel

SELECT id, novel_id, chapter_number, title, price, status, views, created_at, updated_at FROM chapters WHERE novel_id = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED') ORDER BY chapter_number DESC LIMIT 3;
