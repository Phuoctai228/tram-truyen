11. Daily Check-in (UC-32)

b. Class Specifications

UserController Class

No Method Description
01 viewCheckin - Input: authentication: Authentication, model: Model.
- Output: String (View name "user/checkin" or redirect to "/login").
- Internal Method Processing: Handles GET /user/checkin request. Verifies user authentication, retrieves current check-in streak and 7-day roadmap via dailyCheckinService.getCheckinStatus(email) and wallet balance via walletService.getBalance(email), binds them to the model, and renders the check-in page.
02 getCheckinStatusApi - Input: authentication: Authentication.
- Output: ResponseEntity<DailyCheckinStatusDTO>.
- Internal Method Processing: Handles GET /user/checkin/api/status AJAX request for the check-in popup widget. Returns HTTP 401 if unauthenticated; otherwise returns HTTP 200 with the user's DailyCheckinStatusDTO.
03 performCheckin - Input: authentication: Authentication, request: HttpServletRequest, redirectAttributes: RedirectAttributes.
- Output: Object (ResponseEntity<DailyCheckinResultDTO> for AJAX or redirect URL String).
- Internal Method Processing: Handles POST /user/checkin request. Verifies user authentication, executes the daily check-in reward claim via dailyCheckinService.performCheckin(email), and returns the DailyCheckinResultDTO as JSON (for AJAX requests) or sets flash attributes and redirects to /user/checkin.

DailyCheckinService Interface

No Method Description
01 getCheckinStatus - Input: email: String.
- Output: DailyCheckinStatusDTO.
- Internal Method Processing: Retrieves the user's current check-in state, consecutive day streak, and 7-day reward roadmap.
02 performCheckin - Input: email: String.
- Output: DailyCheckinResultDTO.
- Internal Method Processing: Records today's check-in, calculates the streak reward Coins, credits the user's wallet, and returns the check-in result.

DailyCheckinServiceImpl Class

No Method Description
01 getCheckinStatus - Input: email: String.
- Output: DailyCheckinStatusDTO.
- Internal Method Processing: Resolves the User by email, checks if a record exists for today via checkinRepository.findByUserAndCheckinDate(user, today), and inspects the most recent check-in via checkinRepository.findTopByUserOrderByCheckinDateDesc(user). Determines the active 1..7 cycle day (resetting to Day 1 if the streak was broken or completed Day 7), counts total check-in days via checkinRepository.countByUser(user), sums accumulated reward coins via checkinRepository.sumRewardCoinByUser(user), constructs the 7-day roadmap via buildRoadmap(), and returns DailyCheckinStatusDTO.
02 performCheckin - Input: email: String.
- Output: DailyCheckinResultDTO.
- Internal Method Processing: Resolves the User by email and checks checkinRepository.existsByUserAndCheckinDate(user, today); if already checked in today, returns an unsuccessful DailyCheckinResultDTO. Otherwise, inspects yesterday's check-in via checkinRepository.findByUserAndCheckinDate(user, yesterday) to compute newStreak (1 to 7), determines rewardCoin (15 Coins on Day 7, 5 Coins on Days 1-6), saves the new UserDailyCheckin record, credits the user's wallet via walletService.addCoins(user, rewardCoin, "GIFT_COIN", checkinId, description), and returns the updated DailyCheckinResultDTO.
03 buildRoadmap - Input: currentCycleDay: int, isCheckedInToday: boolean.
- Output: List<DayRoadmapItemDTO>.
- Internal Method Processing: Generates the 7-day check-in roadmap items (Days 1-6 with 5 Coins, Day 7 with 15 Coins) and assigns each day's status (CLAIMED, TODAY, or UPCOMING).

- Internal Method Processing: Credits Coins to the user's wallet balance and records a ledger transaction.
02 getBalance - Input: email: String.

WalletServiceImpl Class

No Method Description
01 addCoins - Input: user: User, amount: int, transactionType: String, referenceId: Integer, description: String.
- Output: void.
- Internal Method Processing: Acquires a pessimistic write lock on the user row via userRepository.findByIdWithLock(userId), adds amount to walletBalance, saves the updated user via userRepository.save(lockedUser), and inserts a Transaction record with type = "GIFT_COIN" via transactionRepository.save(tx).
02 getBalance - Input: email: String.
- Output: int.
- Internal Method Processing: Looks up the User by email and returns their walletBalance (defaulting to 0 if null).

No Method Description

02 findByIdWithLock - Input: id: Integer.

UserDailyCheckinRepository Interface

No Method Description
01 findByUserAndCheckinDate - Input: user: User, checkinDate: LocalDate.
- Output: Optional<UserDailyCheckin>.
- Internal Method Processing: Retrieves the user's check-in record for a specific calendar date (today or yesterday).
02 findTopByUserOrderByCheckinDateDesc - Input: user: User.

- Internal Method Processing: Retrieves the user's most recent check-in record ordered by checkin_date DESC.

- Internal Method Processing: Checks whether the user has already checked in on the specified date.
04 countByUser - Input: user: User.
- Output: long.
- Internal Method Processing: Counts the total number of daily check-ins completed by the user.
05 sumRewardCoinByUser - Input: user: User.
- Output: Long.
- Internal Method Processing: Calculates the total accumulated reward coins earned by the user across all daily check-ins.
06 save - Input: checkin: UserDailyCheckin.
- Output: UserDailyCheckin.
- Internal Method Processing: Inserts a new daily check-in record into the user_daily_checkins table.

TransactionRepository Interface

d. Database Queries

1. Retrieve authenticated user by email

SELECT id, email, full_name, wallet_balance, status FROM users WHERE email = ?;

2. Find user check-in record for a specific date

SELECT id, user_id, checkin_date, reward_coin, streak_count, created_at FROM user_daily_checkins WHERE user_id = ? AND checkin_date = ?;

3. Retrieve most recent check-in record for streak calculation

SELECT id, user_id, checkin_date, reward_coin, streak_count, created_at FROM user_daily_checkins WHERE user_id = ? ORDER BY checkin_date DESC LIMIT 1;

4. Count total check-in days for user

SELECT COUNT(id) FROM user_daily_checkins WHERE user_id = ?;

5. Calculate total accumulated check-in reward coins for user

SELECT COALESCE(SUM(reward_coin), 0) FROM user_daily_checkins WHERE user_id = ?;

6. Check if user has already checked in today

SELECT EXISTS ( SELECT 1 FROM user_daily_checkins WHERE user_id = ? AND checkin_date = CURRENT_DATE );

7. Insert new daily check-in record

INSERT INTO user_daily_checkins (user_id, checkin_date, reward_coin, streak_count, created_at) VALUES (?, CURRENT_DATE, ?, ?, CURRENT_TIMESTAMP) RETURNING id;

8. Lock user row before crediting check-in reward Coins

SELECT id, email, full_name, wallet_balance, status FROM users WHERE id = ? FOR UPDATE;

9. Update user wallet balance with reward Coins

UPDATE users SET wallet_balance = ?, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

10. Insert GIFT_COIN reward transaction into wallet ledger

INSERT INTO transactions (user_id, amount, balance_after, type, reference_id, description, created_at) VALUES (?, ?, ?, 'GIFT_COIN', ?, ?, CURRENT_TIMESTAMP) RETURNING id;
