7. Audio Reader (UC-25)

b. Class Specifications

NovelController Class

No Method Description
01 readChapterBySlug - Input: slug: String, chapterNumber: Integer, authentication: Authentication, request: HttpServletRequest, model: Model.
- Output: String (View name "novel/reading").
- Internal Method Processing: Handles GET /truyen/{slug}/chuong-{chapterNumber} request. Retrieves the public novel via novelService.getPublicNovelBySlug(slug) and published chapter via chapterService.getPublicChapter(novelId, chapterNumber). Evaluates chapter access permissions via chapterAccessService.checkAccess(novel, chapter, authentication). Supplies readable chapter paragraphs (paragraphs) and unlock flag (isChapterUnlocked) to the "novel/reading" view so the client-side Web Speech API (SpeechSynthesis) audio player can synthesize Vietnamese speech with sentence-level karaoke highlighting.

NovelService Interface

No Method Description
01 getPublicNovelBySlug - Input: slug: String.
- Output: Novel.
- Internal Method Processing: Retrieves an active, non-archived novel entity by its URL slug.

NovelServiceImpl Class

No Method Description
01 getPublicNovelBySlug - Input: slug: String.
- Output: Novel.
- Internal Method Processing: Queries novelRepository.findBySlugAndIsDeletedFalseAndStatusNot(slug, "ARCHIVED") and returns the public novel or throws ResourceNotFoundException.

ChapterService Interface

No Method Description
01 getPublicChapter - Input: novelId: Integer, chapterNumber: Integer.
- Output: Chapter.
- Internal Method Processing: Retrieves a published chapter entity by novel ID and chapter number.

ChapterServiceImpl Class

No Method Description
01 getPublicChapter - Input: novelId: Integer, chapterNumber: Integer.
- Output: Chapter.
- Internal Method Processing: Queries chapterRepository.findByNovelIdAndChapterNumberAndIsDeletedFalseAndStatusIn(novelId, chapterNumber, PUBLIC_STATUSES), sanitizes the chapter text, and returns the Chapter entity.

ChapterAccessService Interface

No Method Description
01 checkAccess - Input: novel: Novel, chapter: Chapter, authentication: Authentication.
- Output: ChapterAccessDTO.
- Internal Method Processing: Verifies whether the chapter is readable (free or unlocked VIP) and returns the text paragraphs for audio synthesis.

ChapterAccessServiceImpl Class

No Method Description
01 checkAccess - Input: novel: Novel, chapter: Chapter, authentication: Authentication.
- Output: ChapterAccessDTO.
- Internal Method Processing: Invokes chapterAccessPolicy.resolve() to determine if the user has full reading/listening access. When readable, calls chapterPreviewBuilder.splitParagraphs(content) to segment the chapter into clean paragraphs and returns a ChapterAccessDTO.

ChapterPreviewBuilder Class

No Method Description
01 splitParagraphs - Input: content: String.
- Output: List<String>.
- Internal Method Processing: Splits chapter text into non-empty paragraph blocks rendered in the DOM for sentence-by-sentence TTS playback and karaoke highlighting.
02 buildPreviewParagraphs - Input: content: String, previewLimit: int.
- Output: List<String>.
- Internal Method Processing: Builds a limited preview paragraph list when a paid VIP chapter has not been unlocked (audio reader toolbar is disabled in locked state).

ChapterAccessPolicy Class

No Method Description
01 isPaid - Input: chapter: Chapter.
- Output: boolean.
- Internal Method Processing: Checks if the chapter has status PUBLISHED_VIP and price greater than 0.
02 isPrivileged - Input: roleNames: Set<String>.
- Output: boolean.
- Internal Method Processing: Returns true if the authenticated user has ROLE_ADMIN or ROLE_STAFF.
03 resolve - Input: chapter: Chapter, loggedIn: boolean, privileged: boolean, alreadyUnlocked: boolean, walletBalance: int.
- Output: ChapterAccessStatus.
- Internal Method Processing: Resolves whether the chapter is readable (FREE, STAFF_BYPASS, or UNLOCKED) so the Audio Reader feature can be enabled.

NovelRepository Interface

No Method Description
01 findBySlugAndIsDeletedFalseAndStatusNot - Input: slug: String, status: String.
- Output: Optional<Novel>.
- Internal Method Processing: Queries the database for a non-deleted, non-archived novel matching the given slug.

ChapterRepository Interface

No Method Description
01 findByNovelIdAndChapterNumberAndIsDeletedFalseAndStatusIn - Input: novelId: Integer, chapterNumber: Integer, statuses: List<String>.
- Output: Optional<Chapter>.
- Internal Method Processing: Queries the database for a non-deleted published chapter by novel ID and chapter number.

d. Database Queries

1. Retrieve public novel by slug

SELECT id, title, slug, author, status, is_deleted FROM novels WHERE slug = ? AND is_deleted = FALSE AND status <> 'ARCHIVED';

2. Retrieve published chapter content for Audio TTS playback

SELECT id, novel_id, chapter_number, title, content, price, status, is_deleted FROM chapters WHERE novel_id = ? AND chapter_number = ? AND is_deleted = FALSE AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP', 'PUBLISHED');
