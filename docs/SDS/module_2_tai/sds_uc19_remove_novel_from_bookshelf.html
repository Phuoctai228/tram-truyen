5. Remove Novel from Bookshelf (UC-19)

b. Class Specifications

BookshelfController Class

No Method Description
01 removeNovelFromBookshelf - Input: novelId: Integer, source: String, authentication: Authentication, redirectAttributes: RedirectAttributes.
- Output: String (Redirect URL).
- Internal Method Processing: Handles POST /user/bookshelf/{novelId}/remove request. Validates user authentication; if unauthenticated, redirects to /login. Invokes bookshelfService.removeNovelFromBookshelf(email, novelId), sets a flash success or error message on redirectAttributes, and redirects back to the caller page (e.g., /user/bookshelf or /novel/{novelId}).
02 toggleBookshelfAjax - Input: novelId: Integer, authentication: Authentication.
- Output: ResponseEntity<?>.
- Internal Method Processing: Handles POST /api/user/bookshelf/{novelId}/toggle AJAX request. Validates authentication, checks if the novel is currently in the user's bookshelf via bookshelfService.isNovelInBookshelf(email, novelId), and when present, calls bookshelfService.removeNovelFromBookshelf(email, novelId) and returns a JSON response with inBookshelf: false.

BookshelfService Interface

No Method Description
01 removeNovelFromBookshelf - Input: email: String, novelId: Integer.
- Output: void.
- Internal Method Processing: Removes the specified novel from the authenticated member's personal bookshelf.

BookshelfServiceImpl Class

No Method Description
01 removeNovelFromBookshelf - Input: email: String, novelId: Integer.
- Output: void.
- Internal Method Processing: Looks up the User by email via userRepository.findByEmail(email) and the active Novel by ID via novelRepository.findByIdAndIsDeletedFalse(novelId). Queries bookshelfRepository.findByUserAndNovel(user, novel); if the bookshelf entry does not exist, throws ResourceNotFoundException. Otherwise, deletes the entry via bookshelfRepository.delete(bookshelf) while preserving the user's reading history and unlocked VIP chapters.

BookshelfRepository Interface

No Method Description
01 findByUserAndNovel - Input: user: User, novel: Novel.
- Output: Optional<Bookshelf>.
- Internal Method Processing: Finds the bookshelf record matching the given user and novel.
02 delete - Input: bookshelf: Bookshelf.
- Output: void.
- Internal Method Processing: Deletes the specified Bookshelf entity from the bookshelves table.

UserRepository Interface

No Method Description
01 findByEmail - Input: email: String.
- Output: Optional<User>.
- Internal Method Processing: Retrieves the authenticated member's User entity by email address.

NovelRepository Interface

No Method Description
01 findByIdAndIsDeletedFalse - Input: id: Integer.
- Output: Optional<Novel>.
- Internal Method Processing: Retrieves the non-deleted Novel entity by its primary key ID.

d. Database Queries

1. Retrieve authenticated user by email

SELECT id, email, full_name, status FROM users WHERE email = ?;

2. Retrieve active novel by ID

SELECT id, title, slug, author, status, is_deleted FROM novels WHERE id = ? AND is_deleted = FALSE;

3. Find bookshelf record by user and novel

SELECT id, user_id, novel_id, added_at FROM bookshelves WHERE user_id = ? AND novel_id = ?;

4. Delete bookshelf record

DELETE FROM bookshelves WHERE id = ?;
