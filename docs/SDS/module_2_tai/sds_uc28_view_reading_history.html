10. View Reading History (UC-28)

b. Class Specifications

UserController Class

No Method Description
01 viewHistory - Input: page: int, size: int, authentication: Authentication, model: Model.
- Output: String (View name "user/history" or redirect to "/login").
- Internal Method Processing: Handles GET /user/history request. Validates user authentication, fetches paginated reading history records via readingHistoryService.getReadingHistory(email, page, size), binds historyPage, currentPage, and totalPages to the model, and renders the reading history page.
02 removeHistoryItem - Input: chapterId: Integer, authentication: Authentication, redirectAttributes: RedirectAttributes.
- Output: String (Redirect URL "redirect:/user/history").
- Internal Method Processing: Handles POST /user/history/remove request to delete a single chapter from the user's reading history. Calls readingHistoryService.removeHistoryItem(email, chapterId), sets a flash notification message, and redirects back to /user/history.
03 clearHistory - Input: authentication: Authentication, redirectAttributes: RedirectAttributes.
- Output: String (Redirect URL "redirect:/user/history").
- Internal Method Processing: Handles POST /user/history/clear request to clear all reading history entries for the authenticated user via readingHistoryService.clearHistory(email), attaches a flash confirmation message, and redirects to /user/history.

ReadingHistoryService Interface

No Method Description
01 getReadingHistory - Input: email: String, page: int, size: int.
- Output: Page<ReadingHistoryItemDTO>.
- Internal Method Processing: Retrieves a paginated list of chapters read by the user, ordered by most recent read timestamp.
02 recordChapterAccess - Input: email: String, chapterId: Integer.
- Output: void.
- Internal Method Processing: Records that the user has opened a readable chapter by updating its last access time (readAt) without changing the completion flag (isRead). Invoked by NovelController when a logged-in member opens a readable chapter.
03 removeHistoryItem - Input: email: String, chapterId: Integer.
- Output: void.
- Internal Method Processing: Removes a single chapter from the user's reading history while preserving VIP chapter unlock ownership if applicable.
03 clearHistory - Input: email: String.
- Output: void.
- Internal Method Processing: Clears all reading history items for the specified user while preserving any purchased VIP chapter unlocks.

ReadingHistoryServiceImpl Class

No Method Description
01 getReadingHistory - Input: email: String, page: int, size: int.
- Output: Page<ReadingHistoryItemDTO>.
- Internal Method Processing: Resolves the User via userRepository.findByEmail(email), creates a PageRequest, queries userChapterActivityRepository.findAllByUserAndReadAtIsNotNullOrderByReadAtDesc(user, pageable), and maps each UserChapterActivity entity to ReadingHistoryItemDTO via mapToHistoryDTO().
02 recordChapterAccess - Input: email: String, chapterId: Integer.
- Output: void.
- Internal Method Processing: Resolves the User and Chapter, finds or instantiates UserChapterActivity via userChapterActivityRepository.findByUserAndChapter(user, chapter), updates readAt to current timestamp without modifying isRead, and saves the activity.
03 removeHistoryItem - Input: email: String, chapterId: Integer.
- Output: void.
- Internal Method Processing: Resolves the User and locates the activity via userChapterActivityRepository.findByUserAndChapterId(user, chapterId). If isUnlocked == true, resets isRead = false and readAt = null and saves the entity so the user does not lose VIP chapter ownership; otherwise deletes the activity record via userChapterActivityRepository.delete(activity).
04 clearHistory - Input: email: String.
- Output: void.
- Internal Method Processing: Fetches all read activities for the user via userChapterActivityRepository.findAllByUserAndReadAtIsNotNullOrderByReadAtDesc(user, Pageable.unpaged()). Iterates through each record: if isUnlocked == true, resets isRead = false and readAt = null and saves; otherwise deletes the record.
05 mapToHistoryDTO - Input: activity: UserChapterActivity.
- Output: ReadingHistoryItemDTO.
- Internal Method Processing: Extracts novel metadata (ID, title, slug, author, cover URL), chapter metadata (ID, number, title, VIP flag), and readAt timestamp from the UserChapterActivity entity into a ReadingHistoryItemDTO.

UserRepository Interface

No Method Description
01 findByEmail - Input: email: String.
- Output: Optional<User>.
- Internal Method Processing: Retrieves the user entity by email address.

UserChapterActivityRepository Interface

No Method Description
01 findAllByUserAndReadAtIsNotNullOrderByReadAtDesc - Input: user: User, pageable: Pageable.
- Output: Page<UserChapterActivity>.
- Internal Method Processing: Queries all chapter activity records where read_at IS NOT NULL (chapters accessed) for the given user, sorted by read_at DESC.
02 findByUserAndChapterId - Input: user: User, chapterId: Integer.
- Output: Optional<UserChapterActivity>.
- Internal Method Processing: Finds a specific user-chapter activity record by user entity and chapter ID.
03 save - Input: activity: UserChapterActivity.
- Output: UserChapterActivity.
- Internal Method Processing: Updates the activity record (setting is_read = FALSE and read_at = NULL) when clearing reading history for an unlocked VIP chapter.
04 delete - Input: activity: UserChapterActivity.
- Output: void.
- Internal Method Processing: Deletes the activity record when removing reading history for a regular (non-unlocked) chapter.

d. Database Queries

1. Retrieve authenticated user by email

SELECT id, email, full_name, status FROM users WHERE email = ?;

2. Retrieve paginated reading history with chapter and novel details

SELECT uca.id, uca.user_id, uca.chapter_id, uca.is_read, uca.read_at, uca.is_unlocked, c.chapter_number, c.title AS chapter_title, c.price, n.id AS novel_id, n.title AS novel_title, n.slug AS novel_slug, n.author, n.cover_url FROM user_chapter_activities uca INNER JOIN chapters c ON uca.chapter_id = c.id INNER JOIN novels n ON c.novel_id = n.id WHERE uca.user_id = ? AND uca.read_at IS NOT NULL ORDER BY uca.read_at DESC LIMIT ? OFFSET ?;

3. Find user chapter activity by user ID and chapter ID

SELECT id, user_id, chapter_id, is_read, read_at, is_unlocked, price_paid, unlocked_at FROM user_chapter_activities WHERE user_id = ? AND chapter_id = ?;

4. Reset reading flag while preserving VIP unlock record

UPDATE user_chapter_activities SET is_read = FALSE, read_at = NULL WHERE id = ?;

5. Delete reading history record for non-VIP chapter

DELETE FROM user_chapter_activities WHERE id = ?;
