4. View Bookshelf (UC-18)

b. Class Specifications

BookshelfController Class

No Method Description
01 viewBookshelf - Input: filter: String, q: String, sort: String, page: int, authentication: Authentication, model: Model.
- Output: String (View name "user/bookshelf" or redirect to "/login?redirect=/user/bookshelf").
- Internal Method Processing: Handles GET /user/bookshelf request. Verifies that the user is authenticated; if not, redirects to the login page. Invokes bookshelfService.getBookshelfPage(email, filter, q, sort, page, 8) to fetch filtered, sorted, and paginated bookshelf items (8 items per page) along with reading statistics, adds bookshelfPage to the Model, and returns the "user/bookshelf" view.

BookshelfService Interface

No Method Description
01 getBookshelfPage - Input: email: String, filter: String, query: String, sort: String, page: int, size: int.
- Output: BookshelfPageDTO.
- Internal Method Processing: Retrieves the member's personal bookshelf page with reading progress percentages, tab filtering, keyword search, sorting, and pagination.

BookshelfServiceImpl Class

No Method Description
01 getBookshelfPage - Input: email: String, filter: String, query: String, sort: String, page: int, size: int.
- Output: BookshelfPageDTO.
- Internal Method Processing: Retrieves the User by email via userRepository.findByEmail() and fetches all saved bookshelf records with their associated non-deleted novels via bookshelfRepository.findAllByUserWithNovel(user). Maps each entry to a BookshelfItemDTO using mapToBookshelfItem(). Computes summary counts (totalCount, readingCount, completedCount), applies keyword search on title/author, filters by status tab (ALL, READING, COMPLETED), sorts by recent, name, or progress, paginates the list (8 items/page), and returns a BookshelfPageDTO.
02 mapToBookshelfItem - Input: user: User, bookshelf: Bookshelf.
- Output: BookshelfItemDTO.
- Internal Method Processing: Queries chapterRepository.countByNovelIdAndIsDeletedFalse() for total chapters and existsByNovelIdAndPriceGreaterThanAndIsDeletedFalse() for VIP badge detection. Queries userChapterActivityRepository for the latest read chapter and total read chapter count. Calculates progressPercentage (0–100%), completion flags (isCompleted, isCaughtUp), and target readUrl, then constructs and returns a BookshelfItemDTO.

UserRepository Interface

No Method Description
01 findByEmail - Input: email: String.
- Output: Optional<User>.
- Internal Method Processing: Retrieves the authenticated member's User entity by email.

BookshelfRepository Interface

No Method Description
01 findAllByUserWithNovel - Input: user: User.
- Output: List<Bookshelf>.
- Internal Method Processing: Executes a JPQL JOIN FETCH query to load all bookshelf entries of the user along with their active (non-deleted) Novel entities ordered by added_at descending.

ChapterRepository Interface

No Method Description
01 countByNovelIdAndIsDeletedFalse - Input: novelId: Integer.
- Output: long.
- Internal Method Processing: Counts the total number of non-deleted chapters belonging to the novel.
02 existsByNovelIdAndPriceGreaterThanAndIsDeletedFalse - Input: novelId: Integer, price: Integer (0).
- Output: boolean.
- Internal Method Processing: Checks whether the novel contains any non-deleted chapter with a price greater than 0 (VIP chapter).

UserChapterActivityRepository Interface

No Method Description
01 findFirstByUserAndChapter_NovelAndIsReadTrueOrderByReadAtDescChapter_ChapterNumberDesc - Input: user: User, novel: Novel.
- Output: Optional<UserChapterActivity>.
- Internal Method Processing: Retrieves the most recent read chapter activity of the user for the given novel to determine the current chapter bookmark.
02 countByUserAndChapter_NovelAndIsReadTrue - Input: user: User, novel: Novel.
- Output: long.
- Internal Method Processing: Counts the number of chapters read by the user in the specified novel to compute reading progress percentage.

d. Database Queries

1. Retrieve authenticated user by email

SELECT id, email, full_name, avatar_url, wallet_balance, status, created_at FROM users WHERE email = ?;

2. Retrieve all bookshelf entries with active novels for the user

SELECT b.id, b.user_id, b.novel_id, b.added_at, n.id AS novel_id, n.title, n.slug, n.author, n.cover_url, n.status, n.is_deleted FROM bookshelves b INNER JOIN novels n ON b.novel_id = n.id WHERE b.user_id = ? AND n.is_deleted = FALSE ORDER BY b.added_at DESC;

3. Count total non-deleted chapters of a novel

SELECT COUNT(id) FROM chapters WHERE novel_id = ? AND is_deleted = FALSE;

4. Check if novel has paid VIP chapters

SELECT EXISTS ( SELECT 1 FROM chapters WHERE novel_id = ? AND price > 0 AND is_deleted = FALSE );

5. Retrieve latest read chapter activity for a novel

SELECT uca.id, uca.user_id, uca.chapter_id, uca.is_read, uca.read_at, c.chapter_number, c.title FROM user_chapter_activities uca INNER JOIN chapters c ON uca.chapter_id = c.id WHERE uca.user_id = ? AND c.novel_id = ? AND uca.is_read = TRUE ORDER BY uca.read_at DESC, c.chapter_number DESC LIMIT 1;

6. Count chapters read by user for a novel

SELECT COUNT(uca.id) FROM user_chapter_activities uca INNER JOIN chapters c ON uca.chapter_id = c.id WHERE uca.user_id = ? AND c.novel_id = ? AND uca.is_read = TRUE;
