3. Authentication, Wallet & Payment

3.1 Coin & Payment

*a. View Coin History*

This screen displays transaction history of coin top-ups and chapter unlocks.

Related use cases:

  • UC-M3-F09_View Coin History
UI Design
""
Field Name Field Type Description
***Filter Controls***
Transaction Type Combo Box Single-Choice Values: All (Default), TOPUP_COIN, UNLOCK_CHAPTER, GIFT_COIN
From Date Datepicker Filter starting date
To Date Datepicker Filter ending date
Filter Button Applies date and type filter to transaction table
Current Balance Card Text Displays user's current wallet balance (Coins)
***Data Table***
Transaction ID Integer Unique identifier of transaction
Date & Time Text Timestamp when transaction was recorded
Type Text Type category of transaction
Amount Text Fluctuating amount (+X for deposits/gifts, -X for chapter unlocks)
Balance After Text Wallet balance immediately after transaction
Description Text Details including Order Code or Chapter/Novel unlocked
Database Access
Table CRUD Description
users R Retrieve current wallet balance of user
transactions R Query paginated list of user's transactions matching filters

SQL Commands:

1/ Retrieve current wallet balance of user

SELECT wallet_balance FROM users WHERE id = ?;

2/ Query paginated list of user's transactions matching filters

SELECT id, amount, balance_after, type, reference_id, description, created_at FROM transactions WHERE user_id = ? AND (type = ? OR ? IS NULL) AND created_at >= ? AND created_at <= ? ORDER BY created_at DESC LIMIT ? OFFSET ?;
