3. Authentication, Wallet & Payment

3.1 Coin & Payment

*b. Top-up Coin*

This screen allows Members to process payment via VNPay gateway and automatically credit coins to the wallet.

Related use cases:

  • UC-M3-F11_Top-up Coin

SQL Commands:

1/ Retrieve active coin packages list

SELECT id, name, price, coin_amount FROM coin_packages WHERE status = 'ACTIVE' ORDER BY price ASC;

2/ Create pending order and update status upon receiving VNPay IPN

INSERT INTO topup_orders (user_id, package_id, order_code, amount_vnd, coin_received, status, payment_method) VALUES (?, ?, ?, ?, ?, 'PENDING', 'VNPAY'); UPDATE topup_orders SET status = 'SUCCESS', bank_transaction_code = ?, paid_at = CURRENT_TIMESTAMP, updated_at = CURRENT_TIMESTAMP WHERE order_code = ? AND status = 'PENDING';

3/ Store raw VNPay IPN response payload for debugging and verification

INSERT INTO payment_logs (order_code, raw_payload, ip_address, status) VALUES (?, ?, ?, ?);

4/ Update wallet_balance upon successful payment verification

UPDATE users SET wallet_balance = wallet_balance + ?, updated_at = CURRENT_TIMESTAMP WHERE id = ? RETURNING wallet_balance;

5/ Record TOPUP_COIN balance fluctuation

INSERT INTO transactions (user_id, amount, balance_after, type, reference_id, description) VALUES (?, ?, ?, 'TOPUP_COIN', ?, ?);
