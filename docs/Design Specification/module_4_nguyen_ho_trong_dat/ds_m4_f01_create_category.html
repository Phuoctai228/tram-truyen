4. Category & Taxonomy Management

4.1 Category Management

*a. Create Category*

This screen allows Admin to define and add a new category with name, slug path, and description.

Related use cases:

  • UC-M4-F01_Create Category
UI Design
""
Field Name Field Type Description
***Input Form***
Name* Text Box Name of the genre/category (String, max 100 chars, unique)
Slug* Text Box URL-friendly slug path (e.g. "tien-hiep", max 100 chars, unique)
Description Text Area Brief overview of the genre's themes
***Actions***
Create Category Button Validates unique constraints and inserts category
Cancel Button Returns to category list
Database Access
Table CRUD Description
categories CR Check for duplicate name/slug and insert category
system_audit_logs C Record category creation audit log

SQL Commands:

1/ Check for duplicate name/slug and insert category

SELECT id FROM categories WHERE name = ? OR slug = ?; INSERT INTO categories (name, slug, description) VALUES (?, ?, ?) RETURNING id;

2/ Record category creation audit log

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, new_value, ip_address) VALUES (?, 'CREATE_CATEGORY', 'CATEGORIES', ?, ?, ?);
