4.2 Novel Categorization

*a. Categorize Novel*

This screen allows Staff and Admin to update many-to-many category tags linked to a specific novel.

SQL Commands:

1/ Fetch all categories available in the system

SELECT c.id, c.name, CASE WHEN nc.novel_id IS NOT NULL THEN TRUE ELSE FALSE END AS is_assigned FROM categories c LEFT JOIN novel_categories nc ON c.id = nc.category_id AND nc.novel_id = ? ORDER BY c.name ASC;

2/ Retrieve, add, and remove category associations for the novel
