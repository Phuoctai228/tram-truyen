4. Category & Taxonomy Management

4.1 Category Management

*b. Update Category*

This screen allows Admin to edit the name, slug path, or description of an existing category.

Related use cases:

  • UC-M4-F02_Update Category
UI Design
""
Field Name Field Type Description
***Edit Form***
Category ID Text Unique identifier of category (Read-only)
Name* Text Box Category name, pre-filled (max 100 chars)
Slug* Text Box Slug path, pre-filled (max 100 chars)
Description Text Area Description of the category
***Form Actions***
Update Button Saves modified category values
Cancel Button Cancels changes
Database Access
Table CRUD Description
categories RU Load category details and save updates
system_audit_logs C Audit category update

SQL Commands:

1/ Load category details and save updates

SELECT id, name, slug, description FROM categories WHERE id = ?; UPDATE categories SET name = ?, slug = ?, description = ? WHERE id = ?;

2/ Audit category update

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, new_value, ip_address) VALUES (?, 'UPDATE_CATEGORY', 'CATEGORIES', ?, ?, ?, ?);
