2.1 Reading Progress & History

*a. Save Reading Progress*

This function automatically calculates novel reading percentage and updates the reader's latest chapter bookmark.

Related use cases:

  • UC-M2-F05_Save Reading Progress

Database Access
Table CRUD Description
chapters R Count total published chapters in novel to compute reading percentage
user_chapter_activities CRU Upsert member's reading position with timestamp and read flag

SQL Commands:

1/ Count total published chapters in novel to compute reading percentage

SELECT COUNT(c.id) AS total_chapters, COUNT(uca.chapter_id) AS read_chapters FROM chapters c LEFT JOIN user_chapter_activities uca ON c.id = uca.chapter_id AND uca.user_id = ? AND uca.is_read = TRUE WHERE c.novel_id = ? AND c.status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP') AND c.is_deleted = FALSE;

2/ Upsert member's reading position with timestamp and read flag

INSERT INTO user_chapter_activities (user_id, chapter_id, is_read, read_at) VALUES (?, ?, TRUE, CURRENT_TIMESTAMP) ON CONFLICT (user_id, chapter_id) DO UPDATE SET is_read = TRUE, read_at = CURRENT_TIMESTAMP;
