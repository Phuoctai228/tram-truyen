2.2 Daily Check-in & Rewards

*a. Daily Check-in*

This screen allows Members to check-in daily to receive free bonus Coins for unlocking chapters.

Related use cases:

  • UC-M2-F11_Daily Check-in
UI Design
""
Field Name Field Type Description
***Check-in Dashboard***
Streak Tracker Integer Displays the continuous consecutive check-in streak count (e.g. 5 days)
Today's Status Text Indicates "Available" or "Checked in today"
Bonus Reward Text Coin reward amount for today's check-in
***Actions***
Check-in Now Button Triggers daily check-in and claims Coins (disabled if already claimed)
Reward Rules Hyperlink Modal displaying check-in reward schedule and streak bonuses
Database Access
Table CRUD Description
user_daily_checkins CR Verify user has not checked in today and record check-in date
users RU Credit bonus coin reward to member's wallet balance
transactions C Log GIFT_COIN transaction record in wallet ledger

SQL Commands:

1/ Verify user has not checked in today and record check-in date

SELECT checkin_date, streak_count, reward_coin FROM user_daily_checkins WHERE user_id = ? ORDER BY checkin_date DESC LIMIT 1; INSERT INTO user_daily_checkins (user_id, checkin_date, reward_coin, streak_count) VALUES (?, CURRENT_DATE, ?, ?);

2/ Credit bonus coin reward to member's wallet balance

UPDATE users SET wallet_balance = wallet_balance + ?, updated_at = CURRENT_TIMESTAMP WHERE id = ? RETURNING wallet_balance;

3/ Log GIFT_COIN transaction record in wallet ledger

INSERT INTO transactions (user_id, amount, balance_after, type, reference_id, description) VALUES (?, ?, ?, 'GIFT_COIN', ?, 'Daily check-in reward');
