SQL Commands:

1/ Get novel info

SELECT id, title, author, summary, cover_url, status, views, average_rating FROM novels WHERE id = ? AND is_deleted = FALSE;

2/ Get chapters list

SELECT id, chapter_number, title, price, status, created_at FROM chapters WHERE novel_id = ? AND status IN ('PUBLISHED_REGULAR', 'PUBLISHED_VIP') AND is_deleted = FALSE ORDER BY chapter_number ASC;
