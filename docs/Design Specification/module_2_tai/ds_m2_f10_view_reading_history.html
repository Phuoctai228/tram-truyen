2.1 Reading Progress & History

*b. View Reading History*

This screen allows Members to search and review the list of previously read chapters.

Related use cases:

  • UC-M2-F10_View Reading History
UI Design
""
Field Name Field Type Description
***Search & Filters***
Search Novel Text Box Keyword search for read novel titles
Search Button Filters the history list
Clear All History Button Clears all reading history records
***Data Table***
Cover Image Novel cover image
Novel Title Hyperlink Title of novel; clicks to navigate to Novel Details
Last Read Chapter Hyperlink Chapter number and title; clicks to resume reading
Read Date Text Timestamp when chapter was last read
***Data Actions***
Continue Reading Button Opens reader interface at the latest read chapter
Remove Entry icon Removes selected chapter from reading history
Database Access
Table CRUD Description
user_chapter_activities, chapters, novels R Query member's read chapter activities with novel details
user_chapter_activities D Remove single or all reading history records for the user

SQL Commands:

1/ Query member's read chapter activities with novel details

SELECT n.id AS novel_id, n.title AS novel_title, n.cover_url, c.id AS chapter_id, c.chapter_number, c.title AS chapter_title, uca.read_at FROM user_chapter_activities uca JOIN chapters c ON uca.chapter_id = c.id JOIN novels n ON c.novel_id = n.id WHERE uca.user_id = ? AND uca.is_read = TRUE AND n.is_deleted = FALSE ORDER BY uca.read_at DESC LIMIT ? OFFSET ?;

2/ Remove single or all reading history records for the user

DELETE FROM user_chapter_activities WHERE user_id = ? AND chapter_id = ?;
