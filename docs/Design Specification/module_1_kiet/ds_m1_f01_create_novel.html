1. Novel & Chapter Management

1.1 Novel Management

*a. Create Novel*

This screen allows Staff and Admin to register a new novel into the system with initial metadata.

Related use cases:

  • UC-M1-F01_Create Novel
UI Design
""
Field Name Field Type Description
***Input Form***
Title* Text Box Input the title of the novel (String, max 255 chars, unique check)
Author* Text Box Input the original author's name (String, max 100 chars)
Summary* Text Area Input the synopsis or introduction of the novel
Cover Image File Upload Select and upload a cover photo to Cloudinary (JPG/PNG format)
Initial Status* Combo Box Single-Choice Select publishing status: ONGOING (Default) or ON_HOLD
***Form Actions***
Submit Button Validates inputs, uploads cover image, and saves the novel to the database
Cancel Button Discards inputs and navigates back to the Internal Novel List
Database Access
Table CRUD Description
novels C Insert a new novel record into the database
system_audit_logs C Record novel creation activity by the logged-in staff/admin

SQL Commands:

1/ Insert a new novel record into the database

INSERT INTO novels (title, author, summary, cover_url, status, uploader_id, is_deleted) VALUES (?, ?, ?, ?, ?, ?, FALSE) RETURNING id;

2/ Record novel creation activity by the logged-in staff/admin

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, new_value, ip_address) VALUES (?, 'CREATE_NOVEL', 'NOVELS', ?, ?, ?);
