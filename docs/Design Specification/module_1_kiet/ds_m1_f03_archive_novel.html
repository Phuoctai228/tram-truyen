1. Novel & Chapter Management

1.1 Novel Management

*c. Archive Novel*

This function allows Staff and Admin to temporarily hide a novel from public view by setting its status to ARCHIVED.

Related use cases:

  • UC-M1-F03_Archive Novel
UI Design
""
Field Name Field Type Description
***Confirmation Modal***
Novel Title Text Displays the title of the novel being archived (Read-only)
Archive Notice Text Explains that the novel will be hidden from search and listings
Reason Note Text Area Reason for archiving (e.g. copyright notice, revision required)
***Modal Actions***
Confirm Archive Button Commits status change to ARCHIVED
Cancel Button Closes modal without altering novel status
Database Access
Table CRUD Description
novels U Update novel status to ARCHIVED
system_audit_logs C Record archive action in system audit logs

SQL Commands:

1/ Update novel status to ARCHIVED

UPDATE novels SET status = 'ARCHIVED', updated_at = CURRENT_TIMESTAMP WHERE id = ? AND is_deleted = FALSE;

2/ Record archive action in system audit logs

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, new_value, ip_address) VALUES (?, 'ARCHIVE_NOVEL', 'NOVELS', ?, ?, 'ARCHIVED', ?);
