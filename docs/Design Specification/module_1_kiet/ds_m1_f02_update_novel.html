1. Novel & Chapter Management

1.1 Novel Management

*b. Update Novel*

This screen allows Staff and Admin to modify the details, release progress status, and cover image of an existing novel.

Related use cases:

  • UC-M1-F02_Update Novel
UI Design
""
Field Name Field Type Description
***Novel Details Form***
Novel ID Text Auto-generated unique identifier of the novel (Read-only)
Title* Text Box Novel title, pre-filled with current title (String, max 255 chars)
Author* Text Box Author name, pre-filled with current author (String, max 100 chars)
Summary* Text Area Synopsis of the novel, pre-filled with current summary
Current Cover Image Displays current novel cover thumbnail
Upload New Cover File Upload Upload a replacement cover image to Cloudinary (optional)
Status* Combo Box Single-Choice Values: ONGOING, COMPLETED, ON_HOLD, ARCHIVED
***Form Actions***
Save Changes Button Submits and commits modifications to the database
Reset Button Resets all input fields back to initial values loaded from database
Database Access
Table CRUD Description
novels RU Retrieve existing novel details and update with modified values
system_audit_logs C Log novel update history for auditing

SQL Commands:

1/ Retrieve existing novel details and update with modified values

SELECT id, title, author, summary, cover_url, status FROM novels WHERE id = ? AND is_deleted = FALSE; UPDATE novels SET title = ?, author = ?, summary = ?, cover_url = COALESCE(?, cover_url), status = ?, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

2/ Log novel update history for auditing

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, new_value, ip_address) VALUES (?, 'UPDATE_NOVEL', 'NOVELS', ?, ?, ?, ?);
