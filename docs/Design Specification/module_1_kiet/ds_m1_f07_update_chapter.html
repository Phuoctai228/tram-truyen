1.2 Chapter Management

*b. Update Chapter*

This screen allows Staff and Admin to modify chapter sequence, title, and body content.

Related use cases:

  • UC-M1-F07_Update Chapter
UI Design
""
Field Name Field Type Description
***Edit Chapter Form***
Chapter Number* Integer Sequence number of the chapter
Chapter Title* Text Box Title of the chapter (String, max 255 chars)
Content* Text Area The full text of the chapter
***Form Actions***
Update Chapter Button Saves modified chapter data to the database
Reset Button Resets fields to loaded database state
Database Access
Table CRUD Description
chapters RU Retrieve existing chapter content and commit edits
system_audit_logs C Record chapter modification log

SQL Commands:

1/ Retrieve existing chapter content and commit edits

SELECT id, novel_id, chapter_number, title, content FROM chapters WHERE id = ? AND is_deleted = FALSE; UPDATE chapters SET chapter_number = ?, title = ?, content = ?, updated_at = CURRENT_TIMESTAMP WHERE id = ?;

2/ Record chapter modification log

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, new_value, ip_address) VALUES (?, 'UPDATE_CHAPTER', 'CHAPTERS', ?, ?, ?, ?);
