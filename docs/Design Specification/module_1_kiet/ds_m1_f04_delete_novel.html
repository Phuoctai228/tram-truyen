1. Novel & Chapter Management

1.1 Novel Management

*d. Delete Novel*

This screen/function allows Admin to perform soft deletion on a novel, removing it from active system operations.

Related use cases:

  • UC-M1-F04_Delete Novel
UI Design
""
Field Name Field Type Description
***Deletion Confirmation Dialog***
Confirmation Message Text Warning confirming that the novel and all related chapters will be hidden
Novel Title Verification* Text Box Admin enters the novel title to confirm soft deletion
***Dialog Actions***
Confirm Delete Button Sets is_deleted = TRUE for the selected novel
Cancel Button Cancels the deletion process and closes dialog
Database Access
Table CRUD Description
novels U Set is_deleted flag to TRUE for soft deletion
system_audit_logs C Record deletion audit log including admin ID and timestamp

SQL Commands:

1/ Set is_deleted flag to TRUE for soft deletion

UPDATE novels SET is_deleted = TRUE, updated_at = CURRENT_TIMESTAMP WHERE id = ? AND is_deleted = FALSE;

2/ Record deletion audit log including admin ID and timestamp

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, ip_address) VALUES (?, 'DELETE_NOVEL', 'NOVELS', ?, ?, ?);
