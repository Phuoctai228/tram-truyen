1.2 Chapter Management

*c. Lock/Unlock Chapter*

This function allows Staff and Admin to toggle chapter status to LOCKED to temporarily hide it from the table of contents.

Related use cases:

  • UC-M1-F08_Lock/Unlock Chapter

Table CRUD Description
chapters U Update chapter status between LOCKED and active status
system_audit_logs C Record lock/unlock action

SQL Commands:

1/ Update chapter status between LOCKED and active status

UPDATE chapters SET status = ?, updated_at = CURRENT_TIMESTAMP WHERE id = ? AND is_deleted = FALSE;

2/ Record lock/unlock action

INSERT INTO system_audit_logs (admin_id, action_type, target_entity, target_id, old_value, new_value, ip_address) VALUES (?, 'LOCK_UNLOCK_CHAPTER', 'CHAPTERS', ?, ?, ?, ?);
