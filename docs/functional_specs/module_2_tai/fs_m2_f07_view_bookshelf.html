M2-F07. View Bookshelf

Function Trigger: A logged-in Member navigates to the "My Bookshelf" section via the main navigation menu or user profile dropdown.

Function Description: Displays a personalized list of all novels the user is currently following, indicating their reading progress and providing quick access to resume reading.

Screen Layout:
[Placeholder for UI mockups: Bookshelf Dashboard Page]

Function Details

  • Preconditions
    • The user must be logged in as a Member.
  • Process
    • Retrieve Data:
      • The system fetches the list of novels associated with the user's bookshelf from the database.
      • For each novel, the system retrieves the user's latest reading progress (percentage completed and last read chapter ID).
      • The system checks for any new published chapters since the user's last reading session.
    • Render Bookshelf:
      • The system displays the followed novels in a grid or list format.
      • For each entry, the system shows the novel cover, title, reading progress bar (%), and a "Continue Reading" button linked to the bookmarked chapter.
      • If new chapters are available, the system displays a "New Updates" badge on the novel card.
  • Alternative Flow (Empty Bookshelf)
    • If the user has not added any novels to their bookshelf:
      • The system displays a friendly empty state message suggesting they browse and add novels.
  • Postconditions
    • The user views their curated list of novels and can easily resume reading or manage the list.
  • Error Handling
    • Data Load Failure: The system displays an error message asking the user to refresh the page.
  • Security Measures
    • The system enforces strict access control, ensuring users can only view their own bookshelf based on their session token.
