M2-F04. Audio Reader

Function Trigger: A logged-in Member clicks the "Listen" (Audio) icon/button while on the Read Chapter interface.

Function Description: Converts the textual content of the current chapter into spoken audio using Text-to-Speech (TTS), allowing the user to listen to the novel. Features basic playback controls and reading speed adjustments.

Screen Layout:
[Placeholder for UI mockups: Audio Player overlay/bar on Read Chapter page]

Function Details

  • Preconditions
    • The user must be logged in as a Member.
    • The chapter text must be successfully loaded on the screen.
  • Process
    • Initialize Audio Player:
      • The system displays the audio player controls (Play/Pause, Timeline, Speed Adjustment).
    • Text-to-Speech Conversion:
      • The system extracts the text content of the chapter and processes it through the TTS engine.
    • Playback Control:
      • The system begins playing the audio.
      • The system responds to user interactions with the player (e.g., pausing, changing speed to 1.25x or 1.5x).
    • Auto-Advance (Optional):
      • If the user reaches the end of the chapter audio, the system may prompt or auto-play the next chapter if available and unlocked.
  • Alternative Flow (Unsupported Browser)
    • If the user's browser does not support the required Web Speech API / Audio playback:
      • The system displays a warning message that the audio feature is not supported on this device.
  • Postconditions
    • The user listens to the chapter audio instead of or while reading the text.
  • Error Handling
    • TTS Engine Failure: The system displays an error message stating that the audio could not be generated and suggests refreshing the page.
  • Security Measures
    • Only accessible to authenticated Members. Audio generation applies only to chapters the user is authorized to read (including unlocked VIP chapters).
