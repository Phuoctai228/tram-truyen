M2-F05. Save Reading Progress

Function Trigger: Automatically triggered when a Member scrolls through or finishes reading a chapter.

Function Description: Automatically calculates the percentage of the novel completed based on the current chapter versus total chapters, and updates the bookmark so the user can easily resume reading later via a "Continue Reading" button.

Screen Layout:
[Placeholder for UI mockups: Background process / visible progress bar in Bookshelf]

Function Details

  • Preconditions
    • The user is logged in as a Member.
    • The user is actively on the reading interface of a chapter.
  • Process
    • Calculate Progress:
      • The system determines the index of the current chapter being read relative to the total number of published chapters for the novel.
      • The system calculates the overall completion percentage (e.g., Chapter 10 / 100 total = 10%).
    • Update Database:
      • The system sends a background request to save the current chapter ID as the user's latest bookmark for this specific novel.
      • The system updates the reading progress percentage associated with the user's interaction record for this novel.
  • Alternative Flow (Offline Mode)
    • If the user's device temporarily loses internet connection:
      • The system queues the progress update in local storage and attempts to sync it once the connection is restored.
  • Postconditions
    • The user's reading position is saved. When viewing the novel details or bookshelf later, the "Continue Reading" action will lead directly to this chapter.
  • Error Handling
    • Save Failure: The system logs the failure internally without disrupting the user's reading experience. Retries may occur on subsequent page loads.
  • Security Measures
    • Progress updates are linked strictly to the authenticated user's ID to prevent unauthorized modification of other users' bookmarks.
