M2-F08. Remove Novel from Bookshelf

Function Trigger: A logged-in Member clicks the "Remove" or "Unfollow" button on a novel card within the Bookshelf page, or toggles the status on the Novel Details page.

Function Description: Allows users to unfollow a novel, removing it from their personal Bookshelf so they no longer track its updates or see it in their quick-access list.

Screen Layout:
[Placeholder for UI mockups: Remove button on Bookshelf item / Unfollow state on Novel Details Page]

Function Details

  • Preconditions
    • The user must be logged in as a Member.
    • The specified novel must currently exist in the user's bookshelf.
  • Process
    • Confirmation (Optional based on UI context):
      • If triggered from the Bookshelf page, the system may display a prompt asking the user to confirm the removal.
    • Database Update:
      • The system deletes the bookshelf association record between the user's ID and the novel's ID in the database.
    • Interface Update:
      • If on the Bookshelf page, the system dynamically removes the novel card from the view without requiring a full page reload.
      • If on the Novel Details page, the system updates the button state back to "Add to Bookshelf".
      • The system displays a brief success notification confirming the removal.
  • Postconditions
    • The novel is no longer tracked in the user's bookshelf.
  • Error Handling
    • Deletion Error: If the removal request fails on the backend, the system displays an error message and reverts the UI state to show the novel is still in the bookshelf.
  • Security Measures
    • The backend strictly verifies that the user making the request is the owner of the bookshelf being modified.
