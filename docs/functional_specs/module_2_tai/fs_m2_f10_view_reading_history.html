M2-F10. View Reading History

Function Trigger: A logged-in Member navigates to the "History" tab within their user profile or dashboard.

Function Description: Displays a chronological log of all chapters and novels the user has recently read, allowing them to easily re-visit past reads even if they were not explicitly added to the Bookshelf.

Screen Layout:
[Placeholder for UI mockups: Reading History List Page]

Function Details

  • Preconditions
    • The user must be logged in as a Member.
  • Process
    • Retrieve History Logs:
      • The system queries the reading history logs associated with the user's ID, sorted by the most recent access time.
    • Render History List:
      • The system displays a list showing the novel title, the specific chapter read, and the timestamp (e.g., "Read 2 hours ago").
      • The system provides a link for each entry to directly navigate back to that specific chapter.
  • Alternative Flow (Empty History)
    • If the user has not read any chapters yet:
      • The system displays a message stating that the reading history is empty.
  • Postconditions
    • The user views their past reading activity and can quickly jump back into previously accessed content.
  • Error Handling
    • Fetch Error: The system displays a generic message asking the user to try again later if the history fails to load.
  • Security Measures
    • Reading history is private and strictly accessible only to the authenticated owner of the account.
