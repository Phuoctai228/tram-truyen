M2-F01. View Novels

Function Trigger: The user navigates to the homepage or a category page on the platform.

Function Description: This function displays a public list of available novels, allowing readers to browse titles on the homepage or through categorized lists.

Screen Layout:
[Placeholder for UI mockups: Homepage / Category Page]

Function Details

  • Preconditions
    • The system is operational and the database is accessible.
  • Process
    • Retrieve Novel Data:
      • The system fetches the list of public novels from the database based on the requested context (e.g., all novels for the homepage, or filtered by a specific category).
      • The system applies default sorting (e.g., newest updates first or most viewed).
    • Display Novels:
      • The system renders the list of novels in a grid or list format.
      • The system displays key information for each novel: cover image, title, author, category, latest chapter, and current status (Ongoing/Completed).
  • Alternative Flow (Empty List)
    • If there are no novels available (e.g., in a new category):
      • The system displays a descriptive message indicating that no novels are currently available in this section.
  • Postconditions
    • The user views the list of novels and can proceed to click on a novel to view its details.
  • Error Handling
    • Database Error: The system displays a generic error message indicating that content could not be loaded at this time.
  • Security Measures
    • Only novels with public or published statuses (not archived or deleted) are retrieved and displayed to the user.
