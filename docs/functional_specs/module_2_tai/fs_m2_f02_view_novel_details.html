M2-F02. View Novel Details

Function Trigger: The user clicks on a novel from the homepage, search results, or category list.

Function Description: Displays comprehensive information about a specific novel, including its synopsis, author, status, rating, view count, and the complete chapter index.

Screen Layout:
[Placeholder for UI mockups: Novel Details Page]

Function Details

  • Preconditions
    • The selected novel must exist and not be in a deleted or archived state.
  • Process
    • Fetch Novel Information:
      • The system retrieves the novel's metadata, including title, author, synopsis, cover image, average rating, total views, and categories.
    • Fetch Chapter List:
      • The system retrieves the list of published chapters associated with the novel.
      • The system determines the status of each chapter (e.g., Free, VIP).
    • Render Details Page:
      • The system displays the novel's overview information at the top.
      • The system presents the chapter index in chronological order, clearly marking VIP chapters with an appropriate icon or tag.
      • The system increments the view count for the novel (if applicable based on view-counting logic).
  • Alternative Flow (Novel Not Found or Archived)
    • If the novel is deleted or temporarily archived:
      • The system redirects the user to a "404 Not Found" page or displays a message stating the novel is currently unavailable.
  • Postconditions
    • The user is presented with the full details of the novel and can choose to read a chapter, add it to their bookshelf, or view comments.
  • Error Handling
    • Data Fetch Failure: The system displays an error message indicating that the novel details could not be loaded and prompts the user to refresh the page.
  • Security Measures
    • Draft or locked chapters are not displayed in the chapter index to standard users.
