M2-F03. Read Chapter

Function Trigger: The user clicks on a specific chapter link from the novel details page or their reading history/bookshelf.

Function Description: Provides the text reading interface for a chapter, featuring customizable reading settings (font, size, background) and automatically tracking reading progress for logged-in members.

[Placeholder for UI mockups: Reading Interface Page]

Function Details

  • Preconditions
    • The requested chapter must be published.
    • If the chapter is VIP, the user must be logged in and have previously unlocked it.
  • Process
    • Validate Access Rights:
      • The system checks if the chapter is Free. If yes, it proceeds.
      • If the chapter is VIP, the system verifies if the current user has unlocked access to it.
    • Load Chapter Content:
      • The system retrieves the chapter's textual content and titles from the database.
    • Apply User Preferences:
      • The system retrieves any previously saved reading settings (font size, background color) from local storage or database and applies them to the interface.
    • Render Reading Interface:
      • The system displays the formatted text.
      • The system renders navigation controls (Previous Chapter, Next Chapter, Chapter Index).
    • Record Progress (Member Only):
      • If the user is logged in, the system records this chapter as "read" and updates the latest reading progress for this novel in the background.
  • Alternative Flow (Locked VIP Chapter)
    • If a user attempts to access a VIP chapter they have not unlocked:
      • The system redirects the user to the "Buy Chapter" interface (M2-F09), prompting them to unlock it with Coin.
  • Postconditions
    • The user can read the chapter content. Their progress is saved if they are authenticated.
  • Error Handling
    • Chapter Not Found: The system displays a "Chapter not found" message and provides a link back to the novel's detail page.
  • Security Measures
    • Content is served securely. The backend strictly validates chapter unlocking status before returning the text content of VIP chapters.
