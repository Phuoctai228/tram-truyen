M2-F06. Add Novel to Bookshelf

Function Trigger: A logged-in Member clicks the "Add to Bookshelf" button on a novel details page.

Function Description: Allows users to bookmark or follow a specific novel by adding it to their personal Bookshelf, enabling them to easily track updates and access the novel quickly in the future.

Screen Layout:
[Placeholder for UI mockups: "Add to Bookshelf" button state changes on Novel Details Page]

Function Details

  • Preconditions
    • The user must be logged in as a Member.
    • The novel must not already be in the user's bookshelf.
  • Process
    • User Action:
      • The user initiates the action to add the novel to their bookshelf.
    • Database Update:
      • The system creates a new entry in the bookshelf records linking the user's ID with the selected novel's ID.
    • Interface Update:
      • The system updates the button state on the UI to indicate the novel is now "In Bookshelf" (e.g., changing color or text to "Remove from Bookshelf").
      • The system displays a brief success notification (e.g., toast message) confirming the action.
  • Alternative Flow (Not Logged In)
    • If a Guest user attempts to add a novel to the bookshelf:
      • The system interrupts the action and prompts the user to log in or register to use this feature.
  • Postconditions
    • The novel is successfully added to the user's personal bookshelf and will appear when they view the Bookshelf page.
  • Error Handling
    • Database Conflict (Already Added): If the system detects the novel is already in the bookshelf (e.g., due to a duplicate request), it silently ignores the addition and ensures the UI reflects the correct state.
  • Security Measures
    • The system verifies the user's active session token before allowing any modifications to the bookshelf records.
