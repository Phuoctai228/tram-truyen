Functional Description Template

UC ID and Name: UC-04 Delete Category
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Admin Secondary Actors: None
Trigger: Admin clicks the "Delete" button on the target category row in the category list table.
Description: Allows Admin to delete a category from the system provided no novels are currently assigned to it.
Preconditions:

PRE-1. Admin is logged in with valid credentials (ROLE_ADMIN).

PRE-2. Target category exists in the system.
Postconditions:

POST-1. Category is removed from the database and no longer appears on the interface.
Normal Flow:

A. Delete Category Successfully

  1. Admin accesses the category management page in the Admin interface.
  2. Admin clicks the "Delete" button for the target category.
  3. The system queries the database to check associations between this category and active novels.
  4. The system confirms no novels are attached to this category.
  5. The system displays a delete confirmation dialog.
  6. Admin clicks the "Confirm" button.
  7. The system deletes the category record from the database.
  8. The system displays a category deleted successfully message.
  9. The system updates the category table view.
Alternative Flows:

A.4 Alt Category Contains Novels

  1. The system determines at least one novel is linked to this category.
  2. The system displays a deletion rejected error message due to data constraints.
  3. Back to step 1.

A.6 Alt Cancel Deletion

  1. Admin clicks the "Cancel" button.
  2. The system closes the confirmation dialog.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-7 Database Deletion Error

  1. The system encounters a database exception during deletion.
  2. The system logs the system error.
  3. The system displays a deletion operation failed message.
Priority: Medium, Should Have
Frequency of Use: Low
Business Rules:
  • Data integrity constraint: Cannot delete category if associated novel count > 0. Admin must detach category from all novels before deletion.
Other Information: None.
Assumptions:
  • Admin has a stable internet connection.
