Functional Description Template

UC ID and Name: UC-09 View Leaderboards
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor clicks the "Leaderboards" link on the main navigation bar.
Description: Displays top ranked novels by views across different timeframe tabs: Daily Top, Weekly Top, Monthly Top, All-time Top.
Preconditions:

PRE-1. System is active and novel view tracking data exists.
Postconditions:

POST-1. Actor views the top novel leaderboard matching the active timeframe tab.
Normal Flow:

A. View Leaderboards Successfully

  1. Actor accesses home page or header navigation menu.
  2. Actor clicks the "Leaderboards" link.
  3. The system defaults to selecting the "Daily Top" tab.
  4. The system queries the database for Top 10 or Top 20 novels by view counts in that timeframe.
  5. The system fetches novel metadata (rank index, cover image, title, view count, author).
  6. The system renders the leaderboard UI sorted from rank 1 to N.
Alternative Flows:

A.3 Alt Switch Leaderboard Tab

  1. Actor selects "Weekly Top", "Monthly Top", or "All-time Top" tab.
  2. The system extracts timeframe interval parameter.
  3. The system queries database for view counts within selected interval.
  4. The system refreshes leaderboard listing.
  5. Back to step 6.
Exceptions:

EX-3 Ranking Calculation Error

  1. The system fails to aggregate view statistics due to background sync issues.
  2. The system displays a data updating message using cached leaderboard metrics.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-16
Other Information: Displays special badges for Top 1, Top 2, and Top 3.
Assumptions:
  • Actor has a stable internet connection.
