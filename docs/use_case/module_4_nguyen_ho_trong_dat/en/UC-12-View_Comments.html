Functional Description Template

UC ID and Name: UC-12 View Comments
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor scrolls down to the comment section on the novel detail page or chapter reader page.
Description: Displays reader comments with pagination or infinite scroll, enabling community discussion viewing.
Preconditions:

PRE-1. Target novel or chapter exists and is public.
Postconditions:

POST-1. Actor views public reader comment list.
Normal Flow:

A. View Comments Successfully

  1. Actor accesses novel detail page or chapter reader.
  2. Actor navigates to comment section.
  3. The system extracts novel ID or chapter ID.
  4. The system queries database for public active comments (not hidden/deleted).
  5. The system queries commenter user metadata (display name, avatar) and post timestamp.
  6. The system applies default sort ordering newest comments first.
  7. The system calculates comment pagination metadata.
  8. The system renders comment list with pagination controls or "Load More Comments" button.
Alternative Flows:

A.4 Alt No Comments Yet

  1. The system determines zero comments posted for this novel/chapter.
  2. The system displays an empty comment placeholder encouraging discussion.

A.8 Alt Paginate Comments

  1. Actor clicks next page button or "Load More Comments".
  2. The system queries next page of comment records.
  3. The system appends/updates comment feed UI.
  4. Back to step 8.
Exceptions:

EX-3 Comment Fetch Error

  1. The system encounters a database failure retrieving comments.
  2. The system displays a comment loading temporary error notice.
Priority: Medium, Should Have
Frequency of Use: Very High
Business Rules: BR-19
Other Information: None.
Assumptions:
  • Actor has a stable internet connection.
