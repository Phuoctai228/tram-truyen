Functional Description Template

UC ID and Name: UC-06 Search Novels
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor enters keywords into the search bar or clicks the "Search" button.
Description: Provides a search engine for text novels, supporting keyword search by title, author, auto-suggest dropdown, and advanced query options.
Preconditions:

PRE-1. System is online and search indexing service is active.
Postconditions:

POST-1. Matching novel list based on search criteria is displayed.
Normal Flow:

A. Search Novels Successfully

  1. Actor enters keyword query into the header search bar.
  2. The system renders real-time auto-suggestions for up to 5 top matching novels in a dropdown.
  3. Actor clicks the "Search" button or presses Enter.
  4. The system extracts and sanitizes search input terms.
  5. The system executes dynamic queries matching title and author fields.
  6. The system filters out archived or soft-deleted novels.
  7. The system calculates pagination for the search result set.
  8. The system displays matching novel cards with query context and total result count.
Alternative Flows:

A.2 Alt Select Directly from Auto-Suggest

  1. Actor clicks an entry directly inside the auto-suggest dropdown list.
  2. The system redirects Actor straight to the detail page of that novel.

A.8 Alt No Results Found

  1. The system determines zero novels match the search keywords.
  2. The system displays an empty search result screen with query tips and category suggestions.
Exceptions:

EX-5 Malicious Query Syntax

  1. The system detects script injection or invalid characters in search terms.
  2. The system strips unsafe characters before executing search query.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules:
  • Case-insensitive search supporting both accented and unaccented Vietnamese text matching.
  • Only public novels with status ONGOING or COMPLETED are returned.
Other Information: 300ms input debounce applied to auto-suggest queries.
Assumptions:
  • Actor has a stable internet connection.
