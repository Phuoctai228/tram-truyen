Functional Description Template

UC ID and Name: UC-11 Create Comment
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Member Secondary Actors: None
Trigger: Member enters comment text and clicks the "Post Comment" button.
Description: Allows Member to post discussion comments and reader thoughts on novel details page or chapter reader page.
Preconditions:

PRE-1. Member is authenticated with a valid account.

PRE-2. Novel detail page or chapter reader page is active.
Postconditions:

POST-1. New comment is saved to database and rendered instantly in the comment feed.
Normal Flow:

A. Create Comment Successfully

  1. Member accesses novel detail page or chapter reading view.
  2. Member scrolls down to the comment section.
  3. Member inputs text content into the comment input box.
  4. Member clicks the "Post Comment" button.
  5. The system validates comment text length and formatting.
  6. The system filters text for profanity and spam violations.
  7. The system confirms comment content is valid.
  8. The system saves new comment record into database linked to Member and target novel/chapter.
  9. The system displays a comment posted successfully message.
  10. The system updates comment feed UI prepending the newly posted comment at the top.
Alternative Flows:

A.5 Alt Empty Comment Content

  1. The system determines comment box is empty or contains only whitespace.
  2. The system displays error prompt requiring comment text.
  3. Back to step 3.

A.6 Alt Profanity Violation Detected

  1. The system detects blocked words or offensive text.
  2. The system displays error prompt asking user to revise text content.
  3. Back to step 3.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects user to login page.

EX-8 Comment Privilege Muted/Banned

  1. The system checks Member account has active comment restriction due to policy violations.
  2. The system displays notice that account is temporarily banned from posting comments.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules:
  • Comment length must be between 5 and 1000 characters.
  • Rate limiting enforced (maximum 1 comment per 10 seconds per user) to prevent spam bots.
Other Information: Supports 2-level nested reply threads.
Assumptions:
  • Member has a stable internet connection.
