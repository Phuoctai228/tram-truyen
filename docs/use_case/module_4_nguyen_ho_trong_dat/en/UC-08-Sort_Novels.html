UC ID and Name: UC-08 Sort Novels
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor selects an option from the "Sort by" dropdown menu.
Description: Allows Actor to reorder displayed novel lists based on different criteria (Recently Updated, Most Viewed, Highest Rated, Chapter Count, Alphabetical A-Z).
Preconditions:

PRE-1. Actor is located on the novel catalog, search, or category page.
Postconditions:

POST-1. Current novel list is sorted according to the chosen ordering option.
Normal Flow:

A. Sort Novels Successfully

  1. Actor accesses the novel catalog list.
  2. Actor clicks the "Sort by" dropdown menu.
  3. The system displays available sorting options (Recently Updated, Most Viewed, Highest Rated, Chapter Count, Name A-Z).
  4. Actor selects a specific sorting option.
  5. The system captures the sort order while retaining active search/filter parameters.
  6. The system executes database query appending the corresponding ORDER BY clause.
  7. The system updates the list view displaying novels in the new order.
Alternative Flows:

A.4 Alt Select Default Sorting

  1. Actor selects default option "Recently Updated".
  2. The system re-sorts results descending by latest chapter release timestamp.
  3. Back to step 7.
Exceptions:

EX-5 Invalid Sort Parameter

  1. The system detects non-whitelisted sort URL parameter.
  2. The system automatically falls back to default "Recently Updated" sort order.
Priority: Medium, Should Have
Frequency of Use: High
Business Rules:
  • Default sorting defaults to latest chapter update timestamp (updated_at DESC).
  • Active pagination state and active filter criteria are preserved during re-sorting.
Other Information: None.
Assumptions:
  • Actor has a stable internet connection.
