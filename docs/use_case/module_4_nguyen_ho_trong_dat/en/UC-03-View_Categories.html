UC ID and Name: UC-03 View Categories
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor clicks the "Categories" menu link on the navigation bar or accesses the catalog page.
Description: Displays all available novel categories in the system for users to browse and discover novels.
Preconditions:

PRE-1. System is active and connected to the database.
Postconditions:

POST-1. Actor views the complete list of categories along with associated novel counts.
Normal Flow:

A. View Categories Successfully

  1. Actor accesses the home page or main navigation header.
  2. Actor clicks the "Categories" link.
  3. The system queries all active categories from the database.
  4. The system counts published novels associated with each category.
  5. The system sorts the category list alphabetically or by popularity.
  6. The system renders and displays the category menu/list for the Actor.
Alternative Flows:

A.3 Alt Empty Category List

  1. The system determines no categories have been created in the database.
  2. The system displays a no categories available message.
  3. Back to step 1.
Exceptions:

EX-3 Database Connection Error

  1. The system fails to query the database within timeout limit.
  2. The system displays a network or connection error message.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-10
Other Information: Supports quick dropdown menu on the main navbar.
Assumptions:
  • Actor has a stable internet connection.
