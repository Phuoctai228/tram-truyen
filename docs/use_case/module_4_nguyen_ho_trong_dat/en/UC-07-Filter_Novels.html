Functional Description Template

UC ID and Name: UC-07 Filter Novels
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor selects filter criteria on the filter panel and clicks the "Filter Novels" button.
Description: Allows Actor to narrow down displayed novels based on multiple combined filters such as category tags, publication status (Ongoing / Completed), chapter payment type (Free / VIP), and chapter count ranges.
Preconditions:

PRE-1. Actor is located on the category catalog or novel search page.
Postconditions:

POST-1. Novel list filtered accurately matching selected parameters is displayed.
Normal Flow:

A. Filter Novels Successfully

  1. Actor accesses the catalog/filter page.
  2. Actor selects one or multiple target categories.
  3. Actor selects publication status (All, Ongoing, Completed).
  4. Actor selects chapter range or access type (Free / VIP).
  5. Actor clicks the "Filter Novels" button.
  6. The system constructs dynamic specification query based on selected filter parameters.
  7. The system queries the database to extract novels matching all criteria.
  8. The system calculates pagination metadata.
  9. The system renders filtered novel cards.
Alternative Flows:

A.5 Alt Reset Filters

  1. Actor clicks the "Reset" button.
  2. The system clears all selected filter checkboxes and options back to default.
  3. The system reloads the default novel catalog list.

A.9 Alt No Novels Match Filter

  1. The system determines zero novels satisfy the combined filter query.
  2. The system displays a no novels match filter feedback message.
  3. Back to step 2.
Exceptions:

EX-6 Invalid Filter Parameter

  1. The system detects negative chapter counts or malformed filter URL params.
  2. The system automatically resets parameters to default values and continues processing.
Priority: High, Must Have
Frequency of Use: High
Business Rules:
  • Selecting multiple categories applies AND or OR combination logic per interface settings.
  • Resets page number back to Page 1 on filter state modifications.
Other Information: None.
Assumptions:
  • Actor has a stable internet connection.
