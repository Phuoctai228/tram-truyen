Functional Description Template

UC ID and Name: UC-05 Categorize Novel
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Staff, Admin Secondary Actors: None
Trigger: Actor clicks the "Assign Categories" button or opens category settings in novel management.
Description: Allows staff/admin to configure and update Many-to-Many category associations for each novel (attach or detach category tags).
Preconditions:

PRE-1. Actor is logged in as Staff or Admin.

PRE-2. Target novel exists in the system.
Postconditions:

POST-1. Novel category mapping is updated successfully.
Normal Flow:

A. Categorize Novel Successfully

  1. Actor accesses the novel management detail page or edit form.
  2. Actor clicks the "Select Categories" area.
  3. The system queries all active categories from the database.
  4. The system queries categories currently assigned to this novel.
  5. The system displays a multi-select category checklist with current tags pre-checked.
  6. Actor checks additional categories or unchecks unwanted ones.
  7. Actor clicks the "Save Categories" button.
  8. The system validates selected category count limits.
  9. The system updates novel-category mapping table (novel_categories) in database.
  10. The system displays a categorization updated successfully message.
  11. The system refreshes category badge tags on the novel page.
Alternative Flows:

A.7 Alt Cancel Selection

  1. Actor clicks the "Cancel" button.
  2. The system discards modifications and restores previous category tags.
  3. Back to step 1.

A.8 Alt No Category Selected

  1. The system determines Actor unchecked all categories.
  2. The system displays a validation warning requiring at least one category tag.
  3. Back to step 6.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-9 Mapping Update Database Failure

  1. The system encounters a database failure during relation update.
  2. The system rolls back the transaction.
  3. The system displays a categorization update failed message.
Priority: High, Must Have
Frequency of Use: Medium
Business Rules:
  • Each novel must have a minimum of 1 category and a maximum of 5 categories.
  • Mapping updates must be performed within a single database transaction block.
Other Information: None.
Assumptions:
  • Actor has a stable internet connection.
