UC ID and Name: UC-02 Update Category
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Admin Secondary Actors: None
Trigger: Admin clicks the "Edit" icon/button on the target category row in the category list table.
Description: Allows Admin to edit existing category details (category name, slug, description).
Preconditions:

PRE-1. Admin is logged into the system with a valid session.

PRE-2. Target category exists in the database.
Postconditions:

POST-1. Category details are updated successfully in the database.
Normal Flow:

A. Update Category Successfully

  1. Admin accesses the category management page in the Admin interface.
  2. Admin clicks the "Edit" button on the target category.
  3. The system retrieves category details from the database.
  4. The system displays the edit category form pre-filled with current data.
  5. Admin updates category name, slug, or description.
  6. Admin clicks the "Update" button.
  7. The system validates input data correctness.
  8. The system queries the database to check for name/slug collisions with other categories.
  9. The system confirms the updated information is valid.
  10. The system saves modified category details into the database.
  11. The system displays a category updated successfully message.
  12. The system refreshes the category table view.
Alternative Flows:

A.5 Alt Cancel Operation

  1. Admin clicks the "Cancel" button.
  2. The system closes the edit form without saving changes.
  3. Back to step 1.

A.7 Alt Invalid Input

  1. The system determines that input fields are empty or improperly formatted.
  2. The system displays error feedback at the corresponding fields.
  3. Back to step 5.

A.9 Alt Name or Slug Conflict

  1. The system determines that name or slug collides with another existing category.
  2. The system displays a duplicate category data error message.
  3. Back to step 5.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-3 Category Not Found

  1. The system determines that the category was removed by a concurrent process.
  2. The system displays a category not found error message.
  3. The system refreshes the category list.
Priority: Medium, Should Have
Frequency of Use: Low
Business Rules: BR-07

Assumptions:
  • Admin has a stable internet connection.
