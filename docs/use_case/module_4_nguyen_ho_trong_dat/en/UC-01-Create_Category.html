Functional Description Template

UC ID and Name: UC-01 Create Category
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Admin Secondary Actors: None
Trigger: Admin clicks the "Add Category" button on the category management page.
Description: Allows Admin to create a new novel category in the system (category name, URL slug, description) for content categorization.
Preconditions:

PRE-1. Admin is logged into the system with a valid session.

PRE-2. Admin has category administration privileges (ROLE_ADMIN).
Postconditions:

POST-1. New category is saved successfully to the database and displayed in the category list.
Normal Flow:

A. Create Category Successfully

  1. Admin accesses the category management page in the Admin interface.
  2. Admin clicks the "Add Category" button.
  3. The system displays the category creation form.
  4. Admin enters category name, URL slug, and description.
  5. Admin clicks the "Save" button.
  6. The system validates the form input data.
  7. The system queries the database to check for existing category name and slug.
  8. The system confirms the category name and slug are unique.
  9. The system saves the new category information into the database.
  10. The system displays a successful category creation message.
  11. The system updates the displayed category list.
Alternative Flows:

A.4 Alt Cancel Operation

  1. Admin clicks the "Cancel" button.
  2. The system closes the category creation form without saving data.
  3. Back to step 1.

A.6 Alt Invalid Input Data

  1. The system determines that the category name or slug is empty or exceeds length limits.
  2. The system displays an invalid input error message at the respective fields.
  3. Back to step 4.

A.8 Alt Duplicate Name or Slug

  1. The system determines that the category name or slug already exists in the database.
  2. The system displays a duplicate category data error message.
  3. Back to step 4.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-9 Database Save Failure

  1. The system encounters a database connection error or disruption while writing data.
  2. The system logs the system failure.
  3. The system displays an operation failed error message.
Priority: High, Must Have
Frequency of Use: Low
Business Rules:
  • Category name and URL slug must be unique system-wide.
  • Slug must conform to standard URL format (lowercase, numbers, hyphens, no spaces or special characters).
Other Information: None.
Assumptions:
  • Admin has a stable internet connection.
