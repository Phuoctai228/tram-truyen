Functional Description Template

UC ID and Name: UC-10 Review Novel
Created By: Nguyen Ho Trong Dat Date Created: 2026-09-20
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Write Review" button or selects rating stars on the novel detail page.
Description: Allows Member to give star ratings (1-5 stars) and write review feedback; system automatically recalculates novel average_rating.
Preconditions:

PRE-1. Member is authenticated with a valid account.

PRE-2. Target novel is active and published.
Postconditions:

POST-1. Member review is recorded and novel average score is updated.
Normal Flow:

A. Review Novel Successfully

  1. Member accesses novel detail page.
  2. Member clicks the "Write Review" button.
  3. The system displays review modal with 1-5 star selector and review text area.
  4. Member selects star count.
  5. Member inputs review text.
  6. Member clicks the "Submit Review" button.
  7. The system validates star range (1 to 5).
  8. The system queries database checking if Member previously reviewed this novel.
  9. The system confirms this is a new review submission.
  10. The system saves review record into database.
  11. The system recalculates average rating score and total review count.
  12. The system updates novel table metadata in database.
  13. The system displays a review submitted successfully message.
  14. The system updates rating score display and review feed on UI.
Alternative Flows:

A.6 Alt Cancel Review

  1. Member clicks the "Cancel" button.
  2. The system closes the review modal.
  3. Back to step 1.

A.9 Alt Already Reviewed (Update Review)

  1. The system determines Member already submitted a review record for this novel.
  2. The system updates existing review record with new star rating and text.
  3. Skip to step 11.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays authentication error requiring login.
  2. The system redirects user to login page.

EX-7 Star Rating Unselected

  1. Member submits without picking star count.
  2. The system displays error prompt requiring star selection.
Priority: High, Must Have
Frequency of Use: Medium
Business Rules: BR-17
Other Information: None.
Assumptions:
  • Member has a stable internet connection.
