Functional Description Template

UC ID and Name: UC-02 View Novel Details
Created By: Tài Date Created: 2026-09-18
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor clicks on a novel card or title from any list view.
Description: Displays comprehensive metadata about a single novel, including its synopsis, average rating, and a paginated list of its chapters. Provides interaction points for reading, bookmarking, and reviewing.
Preconditions:

PRE-1. The requested novel must exist in the database and have a public status.
Postconditions:

POST-1. The actor is presented with the novel details and chapter index.
Normal Flow:

A. View Details Successfully

  1. Actor clicks on a specific novel.
  2. The system extracts the unique novel identifier from the request.
  3. The system retrieves the novel's core metadata (title, author, synopsis, cover image).
  4. The system calculates the novel's average rating and total view count.
  5. The system retrieves the paginated list of published chapters for the novel.
  6. The system determines the access status (Free vs. VIP) for each retrieved chapter.
  7. The system triggers an asynchronous background job to increment the novel's total view count.
  8. The system checks if the current actor is an authenticated Member and has bookmarked this novel.
  9. The system renders the novel details page, displaying metadata, the chapter list, and action buttons ("Read First Chapter", "Add to Bookshelf").
Alternative Flows:

A.8 Alt Already Bookmarked

  1. The system determines the current Member has already bookmarked the novel.
  2. The system changes the action button state to "Remove from Bookshelf".
  3. Proceed to step 9.
Exceptions:

EX-3 Novel Not Found

  1. The system determines the requested novel ID does not exist, has been deleted, or has an unpublished status.
  2. The system displays a 404 Not Found error page.
Priority: High, Must Have
Frequency of Use: High
Business Rules:
  • Draft or locked chapters (DRAFT, LOCKED) are not retrieved or displayed in the index for standard actors (Guest, Member).
  • VIP chapters (PUBLISHED_VIP) must be visually distinct in the chapter list (e.g., displaying a lock icon or a Coin price tag).
Other Information: None
Assumptions:
  • Actor has a stable internet connection.
