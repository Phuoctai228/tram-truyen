UC ID and Name: UC-10 View Novel Details
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor clicks on a novel card or title from any list view.
Description: Displays comprehensive metadata about a single novel, including its synopsis, average rating, and a paginated list of its chapters. Provides interaction points for reading, bookmarking, and reviewing.
Preconditions:

PRE-1. The requested novel must exist in the database and have a public status.
Postconditions:

POST-1. The actor is presented with the novel details and chapter index.
Normal Flow:

A. View Details Successfully

  1. Actor accesses the novel details page.
  2. The system extracts the unique novel identifier from the request.
  3. The system retrieves the novel's core metadata.
  4. The system calculates the novel's average rating and total view count.
  5. The system retrieves the paginated list of published chapters for the novel.
  6. The system determines the access status for each retrieved chapter.
  7. 7a. The system triggers an asynchronous background job to increment the novel's total view count.
  8. The system retrieves the current actor's session data.
  9. The system checks if the actor has bookmarked the novel.
  10. The system renders the novel details page, displaying descriptive metadata, the chapter list, and action buttons ("Đọc chương đầu", "Thêm vào Tủ sách").
Alternative Flows:

A.9 Already Bookmarked

  1. The system determines the actor is an authenticated Member and has bookmarked the novel.
  2. The system prepares the action button state as "Xóa khỏi Tủ sách".
  3. Back to step 10.
Exceptions:

EX-3 Novel Not Found

  1. The system determines the requested novel ID does not exist, has been deleted, or has an unpublished status.
  2. The system displays a 404 error page.
Priority: High, Must Have
Frequency of Use: High
Business Rules: BR-11
Other Information: UI display varies depending on the actor's role (Guest/Member vs Staff/Admin).
Assumptions:
  • Actor has a stable internet connection.
