UC ID and Name: UC-32-Daily Check-in
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member navigates to the Daily Check-in page via "Điểm danh nhận Coin" in the user dropdown menu (or "Điểm danh hàng ngày" in the profile sidebar) and clicks the "Điểm danh nhận ngay" button.
Description: Allows an authenticated Member to check in once per server calendar day to maintain a 7-day consecutive streak and earn free gift Coins (+5, +5, +10, +10, +15, +15, +30 Coins).
Preconditions:

PRE-1. Member is logged into the system.

PRE-2. Member has not yet checked in on the current server calendar date.
Postconditions:

POST-1. A new daily check-in record is saved in user_daily_checkins with today's date, updated streak count, and rewarded Coin amount.

POST-2. The Member's gift Coin balance is credited and a GIFT_COIN wallet transaction is recorded.
Normal Flow:

A. Complete Daily Check-in Successfully

  1. Member accesses the Daily Check-in page.
  2. The system retrieves the Member's current check-in status, consecutive streak count, and 7-day reward roadmap (+5, +5, +10, +10, +15, +15, +30 Coins).
  3. Member clicks the "Điểm danh nhận ngay" button.
  4. The system validates that no check-in record exists for the Member on the current server date.
  5. The system checks whether a check-in record exists for yesterday to calculate the new consecutive streak day (incrementing the streak or resetting to Day 1 if missed or after completing Day 7).
  6. The system saves the new check-in record in user_daily_checkins and credits the corresponding gift Coins to the Member's wallet within a single transaction.
  7. The system reloads the Daily Check-in page, disables the button with the label "Đã điểm danh hôm nay", updates the displayed Coin balance, and shows a reward toast notification.
Alternative Flows:

A.2 Already Checked In Today

  1. The system detects that the Member has already checked in on the current server date.
  2. The system renders the check-in button in a disabled state with the label "Đã điểm danh hôm nay" (and if a duplicate request is submitted, returns a warning message without crediting Coins).
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-6 Database Transaction Error

  1. The system fails to save the check-in record or credit the wallet due to a database error.
  2. The system rolls back the transaction and displays an error flash message on the check-in page.
Priority: Low, Could Have
Frequency of Use: High (Once per user per day)
Business Rules: BR-22
Other Information: 7-day consecutive reward schedule: Day 1 (+5), Day 2 (+5), Day 3 (+10), Day 4 (+10), Day 5 (+15), Day 6 (+15), Day 7 (+30 Coins).
Assumptions:
  • Member has stable internet connection.
