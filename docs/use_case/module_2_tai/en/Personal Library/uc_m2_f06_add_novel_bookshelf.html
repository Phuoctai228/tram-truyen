UC ID and Name: UC-20-Add Novel to Bookshelf
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Thêm vào Tủ sách" button on the novel details page or clicks the "bookmark" icon ("Lưu vào tủ sách") on the chapter reading toolbar.
Description: Allows an authenticated Member to save a novel to their personal Bookshelf for quick access and reading progress tracking.
Preconditions:

PRE-1. Member is logged into the system.

PRE-2. The target novel exists and is publicly visible.

PRE-3. The novel is not currently in the Member's bookshelf.
Postconditions:

POST-1. A new bookshelf record linking the Member and the novel is saved in the database.

POST-2. The UI updates the button state to "Đã lưu trong Tủ sách" (or active "bookmark" icon).
Normal Flow:

A. Add Novel to Bookshelf Successfully

  1. Member accesses the novel details page or chapter reading page.
  2. Member clicks the "Thêm vào Tủ sách" button (or "bookmark" icon on the reading toolbar).
  3. The system validates the Member's authentication session.
  4. The system verifies the novel exists and is not already in the Member's bookshelf.
  5. The system creates a new bookshelf entry with the current timestamp.
  6. The system updates the UI button to "Đã lưu trong Tủ sách" (or active "bookmark" icon) and displays a confirmation toast notification.
Alternative Flows:

A.4 Novel Already in Bookshelf

  1. The system detects that a bookshelf record already exists for this Member and novel.
  2. The system skips creating a duplicate record and keeps the bookmarked state active.
  3. Back to step 6.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-5 Database Error

  1. The system fails to persist the bookshelf entry due to a database error.
  2. The system displays an error notification indicating the operation could not be completed.
Priority: Medium, Should Have
Frequency of Use: High
Business Rules: BR-03, BR-15
Other Information: Unauthenticated Guests see a "Đăng nhập để lưu Tủ sách" link on the novel details page directing them to log in.
Assumptions:
  • Member has stable internet connection.
