UC ID and Name: UC-18-View Bookshelf
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member selects "Tủ sách" from the header navigation or "Tủ sách của tôi" from the user profile sidebar.
Description: Allows an authenticated Member to view their personal Bookshelf with summary statistics (total, reading, completed), reading progress bars, status filtering, keyword searching, sorting, and pagination (8 novels per page).
Preconditions:

PRE-1. Member is logged into the system.
Postconditions:

POST-1. The Member views their paginated list of bookmarked novels along with each novel's dynamically calculated reading progress.
Normal Flow:

A. View Bookshelf Successfully

  1. Member accesses the personal Bookshelf page.
  2. The system validates the Member's authentication session.
  3. The system retrieves all non-deleted novels in the Member's bookshelf along with the Member's chapter reading activities.
  4. The system calculates each novel's read chapter count, total published chapter count, completion percentage, last read chapter, and reading status, as well as overall bookshelf statistics.
  5. The system applies the selected status filter, search keyword, sort order (defaulting to most recently added), and paginates the results at 8 novels per page.
  6. The system renders the Bookshelf statistics, filter tabs ("Tất cả", "Đang đọc", "Đã xong"), search box, sort dropdown, novel cards with progress bars and action buttons ("Đọc tiếp", "Chờ chương mới", or "Đọc lại"), and pagination controls.
Alternative Flows:

A.3 Empty Bookshelf or No Filter Match

  1. The system determines there are no novels in the Member's bookshelf or none matching the active filter/search criteria.
  2. The system renders an empty state view with the "Khám phá truyện ngay" button (or "Xem tất cả truyện trong tủ" if filtered).
  3. Back to step 1.

A.6.1 Filter, Search, or Sort Bookshelf

  1. Member clicks a status filter tab ("Tất cả", "Đang đọc", "Đã xong"), enters a keyword in the search box, or selects a sort option ("Mới đọc gần đây", "Tên truyện A - Z", "Tiến độ cao nhất").
  2. The system reloads the Bookshelf page with the selected filter, search, and sort parameters.
  3. Back to step 1.

A.6.2 Change Bookshelf Page

  1. Member clicks a page number or the "chevron_left" / "chevron_right" pagination button.
  2. The system loads the requested page of 8 bookshelf items.
  3. Back to step 1.

A.6.3 Continue Reading from Bookshelf

  1. Member clicks the "Đọc tiếp" or "Đọc lại" button on a novel card.
  2. The system navigates the Member to the corresponding chapter reading page.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-3 Database Connection Error

  1. The system fails to retrieve the bookshelf records due to a database error.
  2. The system logs the error and displays an error message.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-13, BR-15
Other Information: Pagination is fixed at 8 novels per page.
If a novel is ongoing and the Member has read all published chapters, the action button is disabled with the label "Chờ chương mới".
Assumptions:
  • Member has stable internet connection.
