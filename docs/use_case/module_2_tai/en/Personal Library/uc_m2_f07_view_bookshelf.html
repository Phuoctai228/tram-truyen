UC ID and Name: UC-18 View Bookshelf
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member navigates to the Bookshelf section from the user profile menu.
Description: Displays a list of all novels the member has bookmarked, showing their current reading progress and providing a quick link to resume reading.
Preconditions:

PRE-1. The user must be authenticated as a Member.
Postconditions:

POST-1. The actor views their personal bookshelf.
Normal Flow:

A. View Bookshelf Successfully

  1. Member clicks on the "Tủ sách" link in the navigation menu.
  2. The system retrieves the current actor's session data.
  3. The system retrieves all bookmark records associated with the member from the database.
  4. The system retrieves the descriptive metadata (title, cover, latest chapter) for each bookmarked novel.
  5. The system calculates the reading progress percentage based on the latest saved chapter index versus total published chapters.
  6. The system renders the bookshelf page, displaying the list of novels with their progress bars and a "Đọc tiếp" button for each.
Alternative Flows:

A.3 Empty Bookshelf

  1. The system determines the member has no bookmark records.
  2. The system renders an empty state illustration with a descriptive message.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.
Priority: High, Must Have
Frequency of Use: High
Business Rules: BR-15
Other Information: None
Assumptions:
  • Member has a stable internet connection.
