UC ID and Name: UC-28-View Reading History
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member selects "Lịch sử đọc" from the user dropdown menu or the profile sidebar.
Description: Allows an authenticated Member to view a chronological log of up to 50 recently read chapters (paginated at 10 items per page), resume reading any chapter, remove individual history entries, or clear their entire reading history.
Preconditions:

PRE-1. Member is logged into the system.
Postconditions:

POST-1. The Member views their paginated reading history ordered by most recently read timestamp.
Normal Flow:

A. View Reading History Successfully

  1. Member accesses the Reading History page.
  2. The system validates the Member's authentication session.
  3. The system queries the Member's read chapter activity records for non-deleted novels and published chapters, ordered by readAt descending and capped at a maximum of 50 records.
  4. The system slices the retrieved records for the requested page (10 records per page).
  5. The system renders the reading history list displaying novel covers, novel titles, chapter numbers and titles, relative read timestamps, "Đọc tiếp" buttons, individual "close" remove buttons, the "Xóa lịch sử" button, and pagination controls.
Alternative Flows:

A.3 Empty Reading History

  1. The system determines the Member has no recorded reading history.
  2. The system renders an empty state view with a "Khám phá truyện" button directing the Member to the homepage.
  3. Back to step 1.

A.5.1 Resume Reading from History

  1. Member clicks the "Đọc tiếp" button (or chapter link) on a history entry.
  2. The system navigates the Member to the corresponding chapter reading page.

A.5.2 Remove Single History Item

  1. Member clicks the "close" icon button ("Xóa khỏi lịch sử") on a history entry.
  2. The system deletes the activity record (or resets isRead = false and readAt = null if the chapter is an unlocked VIP chapter) and reloads the current history page with a confirmation message.
  3. Back to step 1.

A.5.3 Clear All Reading History

  1. Member clicks the "Xóa lịch sử" button and confirms the browser confirmation dialog.
  2. The system clears all reading history entries for the Member (preserving unlocked VIP ownership records by resetting their read flags) and reloads the page with a confirmation message.
  3. Back to step 1.

A.5.4 Change History Page

  1. Member clicks a page number or the "chevron_left" / "chevron_right" button on the pagination controls.
  2. The system loads the requested page of history entries.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-3 Database Query Error

  1. The system fails to retrieve reading history records from the database.
  2. The system logs the error and displays an error message.
Priority: Low, Could Have
Frequency of Use: Medium
Business Rules: BR-14, BR-21
Other Information: Maximum history capacity is 50 entries, paginated at 10 entries per page.
Removing or clearing history never revokes unlocked VIP chapters.
Assumptions:
  • Member has stable internet connection.
