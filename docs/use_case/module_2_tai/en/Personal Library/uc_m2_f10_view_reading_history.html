UC ID and Name: UC-28 View Reading History
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member navigates to the "Lịch sử đọc" section from the profile menu.
Description: Displays a chronologically sorted list of the chapters the member has recently read, allowing them to easily revisit recent reading sessions across different novels.
Preconditions:

PRE-1. The user must be authenticated as a Member.
Postconditions:

POST-1. The actor views their reading history list.
Normal Flow:

A. View History Successfully

  1. Member clicks on the "Lịch sử đọc" link.
  2. The system retrieves the current actor's session data.
  3. The system retrieves the 50 most recent reading history records associated with the member.
  4. The system retrieves the associated novel and chapter metadata for those records.
  5. The system formats the timestamps relative to the current time.
  6. The system renders the history page displaying the list of recently read chapters.
Alternative Flows:

A.3 Empty History

  1. The system determines the member has no reading history records.
  2. The system renders an empty state illustration with a descriptive message.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.
Priority: Low, Nice to Have
Frequency of Use: Low
Business Rules: BR-14
Other Information: None
Assumptions:
  • Member has a stable internet connection.
