UC ID and Name: UC-19 Remove Novel from Bookshelf
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Xóa khỏi Tủ sách" button or trash icon on a novel item.
Description: Allows a member to unfollow a novel and remove it from their personal bookshelf, stopping progress tracking for that specific book.
Preconditions:

PRE-1. The novel must currently exist in the member's bookshelf.
Postconditions:

POST-1. The novel is deleted from the member's bookshelf records.
Normal Flow:

A. Remove Successfully

  1. Member clicks the "Xóa khỏi Tủ sách" button or trash icon.
  2. The system retrieves the current actor's session data.
  3. The system renders a confirmation modal.
  4. Member clicks the "Xác nhận" button.
  5. The system deletes the corresponding bookmark record from the database.
  6. The system removes the novel item from the UI dynamically.
  7. The system displays a success notification message.
Alternative Flows:

A.4 Cancel Deletion

  1. Member clicks the "Hủy" button on the confirmation modal.
  2. The system closes the modal without making any changes.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.
Priority: High, Must Have
Frequency of Use: Medium
Business Rules: BR-15
Other Information: None
Assumptions:
  • Member has a stable internet connection.
