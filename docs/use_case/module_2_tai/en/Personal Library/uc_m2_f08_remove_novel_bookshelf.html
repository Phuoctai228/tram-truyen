UC ID and Name: UC-19-Remove Novel from Bookshelf
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "delete" icon on a novel card in the Bookshelf (or clicks "Đã lưu trong Tủ sách" on the novel details page / active "bookmark" icon on the reading toolbar).
Description: Allows an authenticated Member to remove a bookmarked novel from their personal Bookshelf while preserving their chapter reading progress and reading history.
Preconditions:

PRE-1. Member is logged into the system.

PRE-2. The target novel is currently in the Member's Bookshelf.
Postconditions:

POST-1. The bookshelf record linking the Member and the novel is deleted from the database.

POST-2. The Member's chapter reading history and progress in user_chapter_activities remain intact.
Normal Flow:

A. Remove Novel from Bookshelf Successfully

  1. Member accesses the personal Bookshelf page.
  2. Member clicks the "delete" icon on a novel card.
  3. The system displays a confirmation modal informing the Member that reading progress will remain stored in Reading History.
  4. Member clicks the "Xóa khỏi tủ sách" button in the modal.
  5. The system validates the Member's authentication session.
  6. The system deletes the bookshelf record matching the Member and novel ID from the database.
  7. The system reloads the Bookshelf view and displays a toast notification confirming the removal.
Alternative Flows:

A.2 Remove Directly from Novel Details or Reading Page

  1. Member clicks the "Đã lưu trong Tủ sách" button on the novel details page or the active "bookmark" icon on the reading toolbar.
  2. The system validates the session and deletes the bookshelf record without opening a confirmation modal.
  3. The system updates the button state to "Thêm vào Tủ sách" (or inactive "bookmark" icon).

A.4 Cancel Removal

  1. Member clicks the "Hủy" button or clicks outside the confirmation modal.
  2. The system closes the confirmation modal without deleting the record.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-6 Database Deletion Failure

  1. The system fails to delete the bookshelf record due to a database error.
  2. The system displays an error toast notification.
Priority: Medium, Should Have
Frequency of Use: Medium
Business Rules: BR-15
Other Information: Removing a novel from the Bookshelf only deletes the row in the bookshelves table; all records in user_chapter_activities (read status, timestamps, and unlocked VIP chapters) are preserved.
Assumptions:
  • Member has stable internet connection.
