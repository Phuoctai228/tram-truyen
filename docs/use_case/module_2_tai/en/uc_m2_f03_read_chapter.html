Functional Description Template

UC ID and Name: UC-03 Read Chapter
Created By: Tài Date Created: 2026-09-18
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor clicks on a specific chapter link from the novel details page or bookshelf.
Description: Allows an actor to read the textual content of a published chapter. The system validates access rights (Free vs VIP) and automatically records reading history/progress for authenticated members.
Preconditions:

PRE-1. The requested chapter must exist and have a PUBLISHED status.
Postconditions:

POST-1. The actor reads the chapter content.
Normal Flow:

A. Read Free Chapter Successfully

  1. Actor accesses the reading page for a specific chapter.
  2. The system extracts the chapter ID from the request.
  3. The system validates the chapter's publication status.
  4. The system determines the chapter is Free.
  5. The system retrieves the textual content of the chapter from the database.
  6. The system retrieves the actor's saved reading preferences (e.g., font size, background color) if available.
  7. The system renders the reading interface, displaying the formatted text and navigation controls (Next/Previous).
  8. The system triggers an asynchronous background job to update the novel's total view count.
  9. (Async) If the actor is a Member, the system records the chapter in their reading history and updates their bookmark progress.
Alternative Flows:

A.4 Alt Locked VIP Chapter

  1. The system determines the chapter is a VIP chapter.
  2. The system checks the actor's session and unlock records.
  3. The system determines the actor has not unlocked this chapter.
  4. The system interrupts the reading flow.
  5. The system displays a prompt overlay asking the user to unlock the chapter with Coin.
  6. Back to step 1 (triggered after the actor successfully unlocks it via UC-09).
Exceptions:

EX-3 Chapter Not Found

  1. The system determines the requested chapter ID does not exist or has been unpublished.
  2. The system displays a 404 Not Found message.
  3. The system redirects the actor to the novel's detail page.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-12, BR-13
Other Information: None
Assumptions:
  • Actor has a stable internet connection.
