UC ID and Name: UC-06 View Novel List
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor navigates to the homepage or a specific novel category page via the main navigation menu.
Description: Allows the actor to browse a paginated list of publicly available novels. The system supports dynamic querying to help actors discover content efficiently.
Preconditions:

PRE-1. The system is operational and connected to the database.

PRE-2. There is at least one published novel in the system.
Postconditions:

POST-1. The actor views the paginated list of novels.
Normal Flow:

A. View Novel List Successfully

  1. Actor accesses the homepage or a specific category page.
  2. The system retrieves the current actor's session data.
  3. The system retrieves publicly available novels based on the requested path.
  4. The system sorts the retrieved novels applying default sorting rules.
  5. The system calculates pagination data based on the total result count.
  6. The system displays the list of novels, rendering descriptive elements such as titles, cover images, authors, and summary snippets.
  7. The system renders the pagination controls at the bottom of the list.
Alternative Flows:

A.3 Empty Category

  1. The system determines there are no published novels matching the current category or filter.
  2. The system renders an empty state illustration and a descriptive message.
  3. Back to step 1.

A.7 Change Page

  1. Actor clicks a specific page number, "Trang trước", or "Tiếp theo" button on the pagination controls.
  2. The system calculates the offset for the requested page.
  3. The system queries the database for the novel records on the requested page.
  4. The system updates the UI to display the new set of novels.
  5. Back to step 7.
Exceptions:

EX-3 Database Connection Timeout

  1. The system fails to query the database within the expected time.
  2. The system logs the timeout error.
  3. The system displays a generic error message indicating a temporary service disruption.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-03
Other Information: Pagination limit is set to 20 novels per page.
UI display varies depending on the actor's role (Guest/Member vs Staff/Admin).
Assumptions:
  • Actor has a stable internet connection.
