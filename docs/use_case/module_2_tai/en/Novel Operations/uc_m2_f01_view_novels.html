UC ID and Name: UC-06-View Novel List
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor navigates to the system homepage.
Description: Allows the actor to browse curated lists of non-archived, non-deleted novels on the homepage (featured hero, recently updated, hot, completed, recommended, and new novels).
Preconditions:

PRE-1. The system is operational and connected to the database.
Postconditions:

POST-1. The actor views the curated homepage public novel sections.
Normal Flow:

A. View Novel List Successfully

  1. Actor accesses the homepage.
  2. The system retrieves the current actor's session data.
  3. The system retrieves publicly available (non-deleted, non-archived) novels for each curated section.
  4. The system retrieves the favorite count and top 3 latest published chapters for each novel.
  5. The system checks the bookshelf status for the primary featured novel if the actor is authenticated.
  6. The system displays the curated novel sections with cover images, titles, authors, status, views, ratings, chapter counts, and latest chapters.
Alternative Flows:

A.3 Empty Novel List

  1. The system determines there are no public novels matching the section criteria.
  2. The system renders the homepage with empty states for sections without data.
  3. Back to step 1.
Exceptions:

EX-3.1 Database Connection Timeout

  1. The system fails to query the database within the expected time.
  2. The system logs the timeout error.
  3. The system displays a generic error message indicating a temporary service disruption.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-03, BR-04
Other Information: Homepage displays curated sections: Hero Top 5, Recently Updated Top 12, Hot Top 10, Completed Top 12, Recommended Top 12, New Top 12.
Assumptions:
  • Actor has stable internet connection.
