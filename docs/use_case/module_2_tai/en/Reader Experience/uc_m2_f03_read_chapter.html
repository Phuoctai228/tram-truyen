UC ID and Name: UC-11-Read Chapter
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor selects a chapter from the novel details page, clicks "Đọc truyện" / "Đọc tiếp", or clicks "Chương trước" / "Chương tiếp" on the reading interface.
Description: Allows the actor to read the text content of a published chapter, customize reading appearance settings (theme, font family, font size, line height, content width), navigate between chapters, and view chapter comments.
Preconditions:

PRE-1. The novel is publicly visible (non-deleted and non-archived).

PRE-2. The requested chapter exists, is not soft-deleted, and has a published status.
Postconditions:

POST-1. The actor views the full chapter content (or VIP preview if locked).

POST-2. The chapter and novel view counts are incremented once per user session.
Normal Flow:

A. Read Chapter Successfully

  1. Actor accesses the chapter reading page.
  2. The system retrieves the novel and chapter details and validates that the chapter is published.
  3. The system checks the session view tracker and increments the chapter and novel view counts if not yet counted in the current session.
  4. The system evaluates the actor's access rights for the chapter (free chapter, unlocked VIP chapter, or privileged Staff/Admin role).
  5. The system retrieves adjacent chapters (previous/next), the full published chapter list for the drawer, and chapter comments.
  6. The system renders the reading interface with the full chapter content, navigation buttons ("Chương trước", "Danh sách chương", "Chương tiếp"), and floating toolbar.
Alternative Flows:

A.4 Locked VIP Chapter

  1. The system determines the chapter is a VIP chapter and the actor (Guest or unentitled Member) has not unlocked it.
  2. The system generates a preview excerpt of the chapter content.
  3. The system renders the preview paragraphs along with a VIP paywall card containing the "Mở khóa chương" button and automatically opens the VIP unlock modal.
  4. Back to step 1.

A.6.1 Navigate to Adjacent Chapter

  1. Actor clicks the "Chương trước" or "Chương tiếp" button (or selects a chapter from the "Danh sách chương" drawer).
  2. The system loads the selected chapter page.
  3. Back to step 1.

A.6.2 Customize Reading Settings

  1. Actor clicks the "settings" icon ("Cài đặt hiển thị") on the floating toolbar.
  2. Actor adjusts theme, font family, font size, line height, or content width, or clicks "Đặt lại mặc định".
  3. The system applies the visual changes immediately and saves the preferences to browser localStorage.
  4. Back to step 6.
Exceptions:

EX-2 Chapter Not Found or Unpublished

  1. The system determines the requested chapter does not exist, is soft-deleted, or is not published.
  2. The system throws a resource not found error and displays the 404 error page.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-11, BR-12, BR-13, BR-16, BR-21
Other Information: Staff and Admin actors have privileged access to read VIP chapters without purchasing.
View count deduplication is enforced per HTTP session via the session attribute VIEWED_CHAPTER_IDS.
Assumptions:
  • Actor has stable internet connection.
