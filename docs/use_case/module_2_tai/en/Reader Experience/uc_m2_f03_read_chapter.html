UC ID and Name: UC-11 Read Chapter
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member Secondary Actors: None
Trigger: Actor clicks on a specific chapter link from the novel details page or bookshelf.
Description: Allows an actor to read the textual content of a published chapter. The system validates access rights (Free vs VIP) and automatically records reading history/progress for authenticated members.
Preconditions:

PRE-1. The requested chapter must exist in the system.
Postconditions:

POST-1. The actor reads the chapter content.
Normal Flow:

A. Read Free Chapter Successfully

  1. Actor accesses the reading page for a specific chapter.
  2. The system extracts the chapter ID from the request.
  3. The system retrieves the chapter data from the database.
  4. The system validates the chapter's publication status is published.
  5. The system determines the chapter access level is Free.
  6. The system retrieves the textual content of the chapter from the database.
  7. The system retrieves the actor's session data.
  8. The system retrieves the actor's saved reading preferences (e.g., font size, background color).
  9. The system renders the reading interface, displaying the formatted text and navigation controls ("Chương trước", "Chương sau").
  10. 10a. The system triggers an asynchronous background job to update the novel's total view count.
  11. 11a. If the actor is a Member, the system triggers an asynchronous background job to record the chapter in their reading history and update their bookmark progress.
Alternative Flows:

A.5 Locked VIP Chapter

  1. The system determines the chapter access level is VIP.
  2. The system checks the actor's session and unlock records.
  3. The system validates the actor has not unlocked this chapter.
  4. The system displays a prompt overlay asking the user to unlock the chapter, presenting an "Mở khóa" button.
  5. Back to step 1 (triggered after the actor successfully unlocks it via UC-26).
Exceptions:

EX-3 Chapter Not Found

  1. The system determines the requested chapter ID does not exist in the database.
  2. The system displays a 404 error page.

EX-4 Chapter Unpublished

  1. The system determines the chapter's publication status is unpublished.
  2. The system displays an error message indicating the chapter is currently unavailable.
Priority: High, Must Have
Frequency of Use: Very High
Business Rules: BR-12, BR-13
Other Information: None
Assumptions:
  • Actor has a stable internet connection.
