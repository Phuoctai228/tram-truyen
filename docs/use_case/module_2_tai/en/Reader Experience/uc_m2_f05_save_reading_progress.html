UC ID and Name: UC-27 Save Reading Progress
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member successfully loads and reads a chapter on the reading interface.
Description: Automatically tracks and saves the member's reading progress (percentage and latest chapter ID) in the background while they are reading a novel, updating their bookshelf bookmark.
Preconditions:

PRE-1. The chapter content must be loaded successfully.

PRE-2. The user must be authenticated as a Member.
Postconditions:

POST-1. The member's reading progress is synchronized with the database.
Normal Flow:

A. Save Progress Successfully

  1. Member reads a chapter on the reading interface.
  2. The system determines the numerical index of the current chapter relative to the novel's total published chapters.
  3. The system calculates the overall completion percentage.
  4. The system constructs an update payload with the chapter ID and calculated percentage.
  5. 5a. The system triggers an asynchronous background job to persist the reading progress in the database.
Alternative Flows:

None
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system determines the member's session is invalid during the background request.
  2. The system silently drops the progress update.

EX-5 Network Failure

  1. The system encounters a temporary network timeout when saving progress.
  2. The system queues the update locally.
  3. The system attempts to sync again upon the next successful network interaction.
Priority: Medium, Must Have
Frequency of Use: Very High
Business Rules: BR-13
Other Information: Process happens completely asynchronously in the background.
Assumptions:
  • Member maintains a stable internet connection while reading.
