UC ID and Name: UC-25-Audio Reader
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Guest, Member, Staff, Admin Secondary Actors: None
Trigger: Actor clicks the "volume_up" icon ("Nghe đọc") on the floating toolbar while viewing an unlocked or free chapter.
Description: Allows the actor to listen to the chapter content converted to speech in real time using the browser's Web Speech API (SpeechSynthesis), featuring sentence-by-sentence Karaoke highlighting, auto-scrolling, voice selection, and playback speed control.
Preconditions:

PRE-1. Actor is currently viewing a free or unlocked chapter on the reading page.

PRE-2. The actor's browser supports the Web Speech API (SpeechSynthesis).
Postconditions:

POST-1. The chapter text is synthesized into audio and read aloud with synchronized sentence highlighting.
Normal Flow:

A. Listen to Chapter Audio Successfully

  1. Actor clicks the "volume_up" icon ("Nghe đọc") on the reading toolbar.
  2. The system opens the "Nghe đọc truyện" control panel.
  3. The system loads available browser voices (prioritizing Vietnamese voices) and segments the chapter paragraphs into individual sentences.
  4. Actor clicks the "play_arrow" button to start playback.
  5. The system synthesizes speech sentence by sentence, highlights the active sentence in the text, auto-scrolls the viewport, and updates the sentence progress bar.
Alternative Flows:

A.3 No Vietnamese Voice Installed

  1. The system detects that no Vietnamese ("vi") voice is available in the browser.
  2. The system displays a warning banner in the audio panel with a "help_outline" icon button to open the Vietnamese voice installation guide modal.
  3. Back to step 4.

A.5.1 Pause, Resume, Skip, or Stop Audio

  1. Actor clicks the "pause" button to pause, "play_arrow" to resume, "skip_previous" / "skip_next" to jump between sentences, or "stop" / "close" to stop playback.
  2. The system updates the speech synthesis state and sentence highlighting accordingly.
  3. Back to step 5.

A.5.2 Adjust Playback Speed or Voice

  1. Actor adjusts the speed slider (0.5x to 2.0x) or selects a different voice from the dropdown menu.
  2. The system saves the preference to localStorage and restarts synthesis of the current sentence with the new configuration.
  3. Back to step 5.
Exceptions:

EX-3 Browser Does Not Support SpeechSynthesis

  1. The system detects that the browser does not support the Web Speech API.
  2. The system displays an error message inside the audio panel informing the actor that the browser does not support voice reading.
Priority: Low, Could Have
Frequency of Use: Medium
Business Rules: BR-12
Other Information: The "Nghe đọc" button is only rendered when the chapter is unlocked or free.
Voice and playback speed preferences are persisted in browser localStorage.
Assumptions:
  • Actor has stable internet connection and functional audio output hardware.
