UC ID and Name: UC-25 Audio Reader
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Nghe" icon on the reading interface of a chapter.
Description: Allows a member to convert chapter text into audio using Web Speech API functionality directly on the reading interface, providing an accessible reading alternative.
Preconditions:

PRE-1. The chapter text must be successfully loaded on the client side.
Postconditions:

POST-1. The member listens to the audio playback of the chapter.
Normal Flow:

A. Listen to Chapter Successfully

  1. Member clicks the "Nghe" icon on the reading interface.
  2. The system displays the audio player controls.
  3. The system extracts the pure text content of the chapter.
  4. The system initializes the browser's native text-to-speech engine.
  5. The system feeds the extracted text into the speech synthesis queue.
  6. The system begins audio playback.
Alternative Flows:

A.4 Unsupported Browser

  1. The system determines the member's browser does not support the text-to-speech engine.
  2. The system displays a warning message indicating incompatibility.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-4 TTS Engine Failure

  1. The text-to-speech engine fails to generate audio.
  2. The system displays an error message suggesting a page refresh.
  3. The system hides the audio player controls.
Priority: Medium, Should Have
Frequency of Use: Medium
Business Rules: BR-12
Other Information: None
Assumptions:
  • Member has a stable internet connection.
