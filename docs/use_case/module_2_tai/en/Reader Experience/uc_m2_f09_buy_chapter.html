UC ID and Name: UC-26 Unlock Paid Chapter
Created By: TaiTP Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Mở khóa" button on a locked VIP chapter overlay.
Description: Handles the transaction logic for purchasing permanent access to a VIP chapter using the member's Coin balance. Uses strict database locking to prevent race conditions and double-spending.
Preconditions:

PRE-1. The chapter must be marked as PUBLISHED_VIP.

PRE-2. The user must be authenticated as a Member.
Postconditions:

POST-1. Coin balance is deducted and the chapter is permanently unlocked for the member.
Normal Flow:

A. Buy Chapter Successfully

  1. Member clicks the "Mở khóa" button on a VIP chapter overlay.
  2. The system retrieves the current actor's session data.
  3. The system retrieves the current Coin balance of the member.
  4. The system validates the Coin balance is greater than or equal to the chapter price.
  5. The system executes a database transaction to deduct the price, create a transaction log, and create an unlock record.
  6. The system refreshes the page and renders the unlocked reading interface.
Alternative Flows:

A.4 Insufficient Balance

  1. The system determines the member's Coin balance is lower than the chapter price.
  2. The system displays an error message regarding insufficient balance.
  3. The system renders a "Nạp ngay" button linking to the payment page.
  4. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-5 Concurrency Error

  1. The system encounters a database lock timeout.
  2. The system rolls back any pending changes.
  3. The system displays a generic busy error message.
Priority: Critical, Must Have
Frequency of Use: High
Business Rules: BR-20, BR-21
Other Information: None
Assumptions:
  • Member has a stable internet connection.
