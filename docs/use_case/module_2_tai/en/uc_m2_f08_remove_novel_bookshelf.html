Functional Description Template

UC ID and Name: UC-08 Remove Novel from Bookshelf
Created By: Tài Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the "Remove from Bookshelf" button or icon on a novel item.
Description: Allows a member to unfollow a novel and remove it from their personal bookshelf, stopping progress tracking for that specific book.
Preconditions:

PRE-1. The novel must currently exist in the member's bookshelf.
Postconditions:

POST-1. The novel is deleted from the member's bookshelf records.
Normal Flow:

A. Remove Successfully

  1. Member clicks the "Remove from Bookshelf" or trash icon.
  2. The system validates the current session.
  3. The system asks for a confirmation via a popup modal.
  4. Member confirms the deletion.
  5. The system executes a delete query for the corresponding bookmark record.
  6. The system removes the novel item from the UI dynamically.
  7. The system displays a brief success toast notification.
Alternative Flows:

A.4 Alt Cancel Deletion

  1. Member clicks "Cancel" on the confirmation modal.
  2. The system closes the modal without making any changes.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system determines the actor is not logged in.
  2. The system displays an authentication error message.
  3. The system redirects the user to the login page.
Priority: High, Must Have
Frequency of Use: Medium
Business Rules:
  • Removing a novel from the bookshelf also deletes the associated reading progress bookmark for that novel.
Other Information: None
Assumptions:
  • Member has a stable internet connection.
