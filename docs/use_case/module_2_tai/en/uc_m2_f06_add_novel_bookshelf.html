Functional Description Template

UC ID and Name: UC-06 Add Novel to Bookshelf
Created By: Tài Date Created: 2026-09-18
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the `"Add to Bookshelf"` button on a novel details page or reading page.
Description: Allows a member to bookmark or follow a novel by adding it to their personal Bookshelf, enabling quick access and tracking of new updates.
Preconditions:

PRE-1. The novel must exist and be accessible.
Postconditions:

POST-1. The novel is associated with the member's bookshelf in the database.
Normal Flow:

A. Add to Bookshelf Successfully

  1. Member clicks the `"Add to Bookshelf"` button.
  2. The system retrieves the current actor's session data.
  3. The system retrieves the requested novel from the database.
  4. The system validates the requested novel exists and is publicly accessible.
  5. The system validates the novel is not already in the member's bookshelf.
  6. The system creates a new bookshelf record associating the member and the novel.
  7. The system updates the action button state to `"Remove from Bookshelf"`.
  8. The system displays a success notification message.
Alternative Flows:

None
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-5 Already In Bookshelf

  1. The system determines the novel is already bookmarked by the member.
  2. The system ignores the addition request.
  3. The system refreshes the UI to reflect the correct state.
Priority: High, Must Have
Frequency of Use: High
Business Rules: None
Other Information: None
Assumptions:
  • Member has a stable internet connection.
