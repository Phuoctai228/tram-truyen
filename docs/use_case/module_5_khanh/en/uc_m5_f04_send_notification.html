UC ID and Name: UC-04 Send Notification
Created By: Khánh Date Created: 2026-09-23
Primary Actor: Staff, Admin Secondary Actors: None
Trigger: Actor accesses `"Send Notification"` feature within the administrative console.
Description: Enables Staff or Admin to compose and broadcast system-wide announcements to all registered users or dispatch direct targeted notifications to an individual user account.
Preconditions:

PRE-1. The actor is authenticated with Staff or Admin role.
Postconditions:

POST-1. Notification records are stored in the notifications database table and accessible via users' mailboxes.
Normal Flow:

A. Send Notification Successfully

  1. Actor accesses the notification composer page.
  2. The system verifies the actor's administrative authorization.
  3. The system renders the notification composer form including scope selector (System-wide / Specific User), recipient selector, subject, and message content fields.
  4. Actor selects `"System-wide"` broadcast scope.
  5. Actor inputs the announcement subject title.
  6. Actor inputs the announcement body message.
  7. Actor clicks `"Send Notification"` button.
  8. The system validates subject and body message inputs are not empty.
  9. The system persists the broadcast notification record with user_id as NULL in the database.
  10. The system displays a success confirmation message and resets the composer form.
Alternative Flows:

A.4 Send to Specific User

  1. Actor chooses `"Specific User"` broadcast scope.
  2. Actor enters an email or username in the recipient search box.
  3. The system queries and renders matching user accounts.
  4. Actor selects the target recipient from the dropdown.
  5. Proceed with steps 5, 6, 7.
  6. The system saves the notification record with the recipient's user ID.
  7. The system displays a direct notification dispatched confirmation message.

A.8 Missing Required Fields

  1. The system detects either subject or body message is empty.
  2. The system displays a validation error message prompting for missing details.
  3. Back to step 5.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-2 Access Denied

  1. The system determines the user lacks required Staff or Admin privileges.
  2. The system displays a 403 Forbidden page.
Priority: Medium, Should Have
Frequency of Use: Medium
Business Rules: BR-05
Other Information: Broadcast notifications (user_id = NULL) are dynamically populated across all user mailbox queries.
Assumptions:
  • Actor has a stable internet connection.
