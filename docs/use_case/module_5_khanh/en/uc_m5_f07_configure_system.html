Functional Description Template

UC ID and Name: UC-07 Configure System
Created By: KhanhND Date Created: 2026-09-23
Primary Actor: Admin Secondary Actors: None
Trigger: Admin clicks "System Configuration" in the administrative navigation sidebar.
Description: Enables Admin to review and adjust global operational parameters, including VNĐ-to-Coin exchange rates, official administrative contact details (hotline, support email), terms of service, privacy policy, and theme activation.
Preconditions:

PRE-1. The user is authenticated with the Admin role.
Postconditions:

POST-1. New system configuration values are updated in the database and become active immediately.

POST-2. System audit log records Admin identity, modified keys, and old vs new values.
Normal Flow:

A. Configure System Successfully

  1. Admin navigates to the system configuration page.
  2. The system verifies the actor's Admin authorization.
  3. The system retrieves current configuration key-value pairs from the database.
  4. The system queries available UI themes from the themes repository.
  5. The system renders the configuration form with settings (Exchange Rate, Support Email, Hotline, Terms of Service, Active Theme).
  6. Admin modifies the exchange rate value or updates support information in the form fields.
  7. Admin clicks "Save Settings" button.
  8. The system validates input data types (exchange rate must be a positive integer greater than zero, email format valid).
  9. The system executes a database update modifying entries in system_settings table.
  10. The system records an administrative audit log capturing previous and new configuration values.
  11. The system displays a configuration updated successfully confirmation message.
Alternative Flows:

A.8 Invalid Setting Value

  1. The system identifies that the exchange rate is non-positive or email format is invalid.
  2. The system highlights offending fields with descriptive error notifications.
  3. Back to step 6.

A.6 Switch Web Theme

  1. Admin selects a different theme card and clicks "Activate Theme" button.
  2. The system confirms and updates the is_active flag in the themes table.
  3. The system applies the selected theme styles platform-wide.
  4. Back to step 5.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-2 Access Denied

  1. The system determines the user lacks Admin privileges.
  2. The system displays a 403 Forbidden page.

EX-9 Configuration Persistence Failure

  1. The system encounters a database write error during transaction execution.
  2. The system rolls back pending changes and renders an error notification.
Priority: High, Must Have
Frequency of Use: Low (When policy or branding updates occur)
Business Rules: BR-03
Other Information: Adjusted exchange rates apply exclusively to newly initiated deposit orders.
Assumptions:
  • Admin has a stable internet connection.
