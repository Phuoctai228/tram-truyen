Functional Description Template

UC ID and Name: UC-02 Report Content
Created By: Khánh Date Created: 2026-09-23
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks `"Report Error"` or `"Report Violation"` button on novel details page or chapter reader toolbar.
Description: Enables Member to submit an issue report when encountering content defects (typos, missing text, chapter duplicates, corrupted formatting) or policy/copyright violations in a novel or chapter.
Preconditions:

PRE-1. The user is authenticated with the Member role.

PRE-2. The reported novel or chapter exists in the system.
Postconditions:

POST-1. The content report ticket is recorded in the database with a pending status.
Normal Flow:

A. Report Content Successfully

  1. Member clicks `"Report Violation"` button on the novel details page or chapter reading interface.
  2. The system retrieves the current actor's session data.
  3. The system identifies the target scope (novel-wide or specific chapter).
  4. The system renders the content report modal with defect classifications (Corrupted Text, Wrong Chapter Sequence, Copyright Issue, Inappropriate Content, Other) and a description textarea.
  5. Member selects the error type and enters descriptive details.
  6. Member clicks `"Submit Report"` button.
  7. The system validates the description input is not empty.
  8. The system checks that the Member has no pending report for this target.
  9. The system persists the content report record into the database.
  10. The system closes the modal and displays a report submission confirmation message.
Alternative Flows:

A.7 Empty Description

  1. The system detects the description textarea is blank.
  2. The system renders a validation error message prompting for details.
  3. Back to step 5.

A.8 Pending Duplicate Report

  1. The system determines a pending report from this Member for the target entity already exists.
  2. The system displays an informative message that the issue is currently under review.
  3. Back to step 5.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-3 Target Entity Not Found

  1. The system determines the novel or chapter record is missing or soft-deleted.
  2. The system displays an error message indicating content not found.
Priority: Medium, Should Have
Frequency of Use: Medium (When issues are identified)
Business Rules: BR-05
Other Information: Chapter reports automatically associate the chapter number and ID.
Assumptions:
  • Member has a stable internet connection.
