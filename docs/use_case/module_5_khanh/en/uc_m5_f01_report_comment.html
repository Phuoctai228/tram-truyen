UC ID and Name: UC-01 Report Comment
Created By: Khánh Date Created: 2026-09-23
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks `"Report"` button or `"flag"` icon on a specific comment in the reading interface or novel details page.
Description: Allows an authenticated Member to submit a violation report regarding a malicious, offensive, spam, or inappropriate comment to the administration for moderation.
Preconditions:

PRE-1. The user is authenticated with the Member role.

PRE-2. The reported comment exists and is currently visible.
Postconditions:

POST-1. The comment report ticket is created and stored in the database with a pending status.
Normal Flow:

A. Report Comment Successfully

  1. Member clicks `"Report"` button on the target comment.
  2. The system retrieves the current actor's session data.
  3. The system validates the target comment exists and is in a valid state.
  4. The system renders the comment report modal displaying violation categories (Spam, Hate Speech, Harassment, Other) and a detailed reason input field.
  5. Member selects a violation reason category and inputs detailed description.
  6. Member clicks `"Submit Report"` button.
  7. The system validates the report reason input is not empty.
  8. The system checks that the Member has no pending report for this comment.
  9. The system saves the report record into the database with a pending status.
  10. The system closes the modal and displays a success notification message.
Alternative Flows:

A.7 Invalid Reason Input

  1. The system determines the reason description is empty or exceeds length limits.
  2. The system displays an error message requesting valid reason details.
  3. Back to step 5.

A.8 Duplicate Report

  1. The system determines the Member already has a pending report submitted for this comment.
  2. The system displays a warning message that a report has already been submitted.
  3. Back to step 5.

A.5 Cancel Report Action

  1. Member clicks `"Cancel"` button or `"Close"` icon on the report modal.
  2. The system closes the modal without saving any data.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-3 Target Comment Not Found

  1. The system determines the comment was deleted by its author or hidden previously.
  2. The system displays an error message indicating the comment is unavailable.
  3. The system refreshes the comment list in the UI.
Priority: Medium, Should Have
Frequency of Use: Medium (Whenever violations are found)
Business Rules: BR-05
Other Information: None.
Assumptions:
  • Member has a stable internet connection.
