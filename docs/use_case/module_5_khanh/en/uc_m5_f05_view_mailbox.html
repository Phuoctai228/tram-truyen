Functional Description Template

UC ID and Name: UC-05 View Mailbox
Created By: Khánh Date Created: 2026-09-23
Primary Actor: Member Secondary Actors: None
Trigger: Member clicks the mailbox or notifications icon (`"notifications"` icon) in the header navigation bar.
Description: Allows Member to access personal and broadcast system notifications, inspect moderation report feedback, review Coin transaction updates, mark messages as read, or remove individual notifications.
Preconditions:

PRE-1. The user is authenticated with the Member role.
Postconditions:

POST-1. Member views the paginated list of notifications.

POST-2. Target notification status is updated to read when opened.
Normal Flow:

A. View Mailbox Successfully

  1. Member clicks `"notifications"` icon in the top navigation bar.
  2. The system retrieves the current actor's session data.
  3. The system queries notifications associated with the Member (targeted user notifications and global broadcast notifications).
  4. The system orders notifications by creation timestamp descending.
  5. The system computes the unread notification count.
  6. The system displays the notification list accompanied by the unread badge indicator.
  7. Member clicks a specific notification item to read its full message.
  8. The system updates the message status to read in the database.
  9. The system renders the complete notification content modal.
Alternative Flows:

A.3 Empty Mailbox

  1. The system identifies that no notifications exist for this user.
  2. The system displays an empty state graphic and a descriptive message.

A.6 Mark All as Read

  1. Member clicks `"Mark All as Read"` button.
  2. The system executes a bulk update setting is_read = true for all unread notifications of the user.
  3. The system updates the UI and clears the unread badge counter.
  4. Back to step 6.

A.6 Delete Notification

  1. Member clicks `"Delete"` icon on a specific notification item.
  2. The system deletes the notification record from the user's view.
  3. The system refreshes the notification list.
  4. Back to step 6.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-7 Notification Not Found

  1. The system determines the selected notification has already been deleted.
  2. The system displays an error message indicating the message is no longer available.
Priority: High, Must Have
Frequency of Use: Very High (Whenever alerts arrive)
Business Rules: BR-05
Other Information: None.
Assumptions:
  • Member has a stable internet connection.
