Functional Description Template

UC ID and Name: UC-02-Verify Account
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Guest Secondary Actors: None
Trigger: Guest accesses the verification page.
Description: Guest inputs the OTP code to activate their newly registered account.
Preconditions:

PRE-1. Guest must have an account with PENDING_VERIFICATION status.
Postconditions:

POST-1. The account status is changed to ACTIVE.
Normal Flow:

A. Verify Account Successfully

  1. Guest accesses the verification page.
  2. The system displays the OTP verification form.
  3. Guest enters the OTP code.
  4. Guest clicks the "Xác nhận" button.
  5. The system validates the OTP format.
  6. The system verifies the OTP matches the one sent and is not expired.
  7. The system updates the account status to active.
  8. The system displays a success message.
  9. The system redirects Guest to the login page.
Alternative Flows:

A.5.1 Alt Invalid OTP Format

  1. The system detects the OTP format is invalid.
  2. The system displays a validation error message.
  3. Back to step 3.

A.6.1 Alt Incorrect OTP

  1. The system detects the OTP does not match the generated code.
  2. The system displays an error message.
  3. Back to step 3.

A.6.2 Alt Expired OTP

  1. The system detects the OTP has expired.
  2. The system displays an error message prompting to request a new code.
  3. Back to step 3.
Exceptions:

EX-7 Database Connection Failure

  1. The system fails to update the account status due to a database error.
  2. The system displays a system error message.
  3. Back to step 1.
Priority: High
Frequency of Use: High
Business Rules: None
Other Information: None
Assumptions:
  • Guest has stable internet connection.
