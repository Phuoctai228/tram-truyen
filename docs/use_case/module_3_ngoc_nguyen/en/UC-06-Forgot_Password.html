Functional Description Template

UC ID and Name: UC-06-Forgot Password
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Guest Secondary Actors: None
Trigger: Guest accesses the forgot password page.
Description: Guest requests a password reset link sent to their email.
Preconditions:

PRE-1. Guest must not be logged into the system.
Postconditions:

POST-1. A password reset token is generated and sent via email.
Normal Flow:

A. Request Password Reset Successfully

  1. Guest accesses the forgot password page.
  2. The system displays the email input form.
  3. Guest enters their registered email address.
  4. Guest clicks the "Gửi yêu cầu" button.
  5. The system validates the email format.
  6. The system verifies the email exists in the database.
  7. The system generates a secure password reset token.
  8. The system sends an email containing the reset link to the Guest.
  9. The system displays a success message indicating the email has been sent.
Alternative Flows:

A.5.1 Alt Invalid Email Format

  1. The system detects an invalid email format.
  2. The system displays a validation error message.
  3. Back to step 3.

A.6.1 Alt Email Not Found

  1. The system detects that the email is not registered in the system.
  2. The system displays an error message indicating the email was not found.
  3. Back to step 3.
Exceptions:

EX-8 Email Sending Failure

  1. The system fails to send the password reset email.
  2. The system displays an error message.
  3. Back to step 1.
Priority: Medium
Frequency of Use: Low
Business Rules:
  • Reset tokens must have an expiration time.
Other Information: None
Assumptions:
  • Guest has stable internet connection.
