Functional Description Template

UC ID and Name: UC-09-View Coin History
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Member, Staff, Admin Secondary Actors: None
Trigger: Actor accesses the Coin history page.
Description: Actor views a detailed history of their Coin transactions (top-ups and spending).
Preconditions:

PRE-1. Actor must be logged into the system.
Postconditions: None
Normal Flow:

A. View Coin History Successfully

  1. Actor accesses the Coin history page.
  2. The system retrieves the transaction history associated with the Actor's account.
  3. The system displays the transaction history list.
Alternative Flows:

A.3.1 Alt Navigate Pagination

  1. Actor clicks a pagination link.
  2. The system retrieves the transaction history data for the selected page.
  3. Back to step 3.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.
Priority: Medium
Frequency of Use: Medium
Business Rules: None
Other Information: None
Assumptions:
  • Actor has stable internet connection.
