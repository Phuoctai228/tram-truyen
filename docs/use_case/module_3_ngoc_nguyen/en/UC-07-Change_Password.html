Functional Description Template

UC ID and Name: UC-07-Change Password
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Member, Staff, Admin Secondary Actors: None
Trigger: Actor accesses the change password page.
Description: Actor changes their current account password.
Preconditions:

PRE-1. Actor must be logged into the system.
Postconditions:

POST-1. The account password is updated in the database.
Normal Flow:

A. Change Password Successfully

  1. Actor accesses the change password page.
  2. The system displays the change password form.
  3. Actor enters current password, new password, and confirm new password.
  4. Actor clicks the "Đổi mật khẩu" button.
  5. The system validates the input data formats.
  6. The system verifies that the current password matches the database.
  7. The system hashes the new password.
  8. The system updates the password in the database.
  9. The system displays a success message.
Alternative Flows:

A.5.1 Alt Invalid Input Format

  1. The system detects that the new password does not meet complexity requirements.
  2. The system displays a validation error message.
  3. Back to step 3.

A.5.2 Alt Passwords Do Not Match

  1. The system detects that the new password and confirm password do not match.
  2. The system displays a validation error message.
  3. Back to step 3.

A.6.1 Alt Incorrect Current Password

  1. The system detects that the entered current password is wrong.
  2. The system displays an error message.
  3. Back to step 3.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.
Priority: High
Frequency of Use: Low
Business Rules: BR-01
Other Information: None
Assumptions:
  • Actor has stable internet connection.
