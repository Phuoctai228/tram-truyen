UC ID and Name: UC-11-Top-up Coin
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Member Secondary Actors: VNPay Gateway
Trigger: Member accesses the top-up page.
Description: Member tops up their wallet with Coin using the VNPay payment gateway.
Preconditions:

PRE-1. Member must be logged into the system.
Postconditions:

POST-1. The Coin amount is added to the Member's wallet.

POST-2. A deposit transaction record is created.
Normal Flow:

A. Top-up Coin Successfully

  1. Member accesses the top-up page.
  2. The system displays the available top-up packages.
  3. Member selects a package and clicks the "Nạp ngay" button.
  4. The system generates a VNPay payment URL.
  5. The system redirects Member to the VNPay payment gateway.
  6. Member completes the payment on the VNPay interface.
  7. The system receives the IPN webhook response from VNPay.
  8. The system verifies the payment signature using HMAC-SHA512.
  9. The system creates a deposit transaction record.
  10. The system adds the corresponding Coin amount to the Member's wallet.
  11. The system redirects Member to the top-up result page displaying a success message.
Alternative Flows:

A.6.1 Alt Member Cancels Payment

  1. Member clicks the cancel button on the VNPay gateway.
  2. The system receives a cancellation redirect from VNPay.
  3. The system displays a payment cancelled message.
  4. Back to step 2.

A.8.1 Alt Invalid Signature

  1. The system detects an invalid payment signature in the webhook response.
  2. The system rejects the transaction.
  3. The system displays a payment error message.
  4. Back to step 2.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-9 Database Update Failure

  1. The system fails to save the transaction or update the wallet due to a database error.
  2. The system displays a system error message.
  3. Back to step 1.
Priority: High
Frequency of Use: Medium
Business Rules: BR-23
Other Information: None
Assumptions:
  • Member has stable internet connection.
