Functional Description Template

UC ID and Name: UC-03-Login
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Guest Secondary Actors: None
Trigger: Guest accesses the login page.
Description: Guest authenticates into the system using their email and password.
Preconditions:

PRE-1. Guest must not be logged into the system.
Postconditions:

POST-1. A user session is created.
Normal Flow:

A. Login Successfully

  1. Guest accesses the login page.
  2. The system displays the login form.
  3. Guest enters email and password.
  4. Guest clicks the "Đăng nhập" button.
  5. The system validates the input data formats.
  6. The system verifies that the email exists in the database.
  7. The system verifies that the password is correct.
  8. The system verifies that the account status is active.
  9. The system creates a user session.
  10. The system redirects Guest to the home page.
Alternative Flows:

A.5.1 Alt Invalid Input Format

  1. The system detects invalid email or password format.
  2. The system displays a validation error message.
  3. Back to step 3.

A.6.1 Alt Email Not Found

  1. The system detects that the email is not registered.
  2. The system displays an error message indicating invalid credentials.
  3. Back to step 3.

A.7.1 Alt Incorrect Password

  1. The system detects that the password does not match.
  2. The system displays an error message indicating invalid credentials.
  3. Back to step 3.

A.8.1 Alt Account Pending Verification

  1. The system detects that the account is in pending status.
  2. The system displays an error message prompting to verify the account.
  3. Back to step 3.

A.8.2 Alt Account Banned

  1. The system detects that the account is banned.
  2. The system displays an error message indicating the account is locked.
  3. Back to step 3.
Exceptions:

EX-9 Database Connection Failure

  1. The system fails to query the user data due to a database error.
  2. The system displays a system error message.
  3. Back to step 1.
Priority: High
Frequency of Use: High
Business Rules: None
Other Information: Optional "Remember-Me" functionality allows creating persistent cookies.
Assumptions:
  • Guest has stable internet connection.
