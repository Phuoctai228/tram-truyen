Functional Description Template

UC ID and Name: UC-04-Login with Google
Created By: Ngoc Nguyen Date Created: 2026-09-19
Primary Actor: Guest Secondary Actors: Google OAuth2 Server
Trigger: Guest accesses the login page.
Description: Guest authenticates into the system using their Google account.
Preconditions:

PRE-1. Guest must not be logged into the system.
Postconditions:

POST-1. A user session is created.

POST-2. A user account and Coin wallet are automatically generated if they did not exist.
Normal Flow:

A. Login with Google Successfully

  1. Guest accesses the login page.
  2. Guest clicks the "Đăng nhập bằng Google" button.
  3. The system redirects Guest to the Google OAuth2 consent screen.
  4. Guest authorizes the application.
  5. The system receives the Google profile data.
  6. The system verifies if an account with this Google ID exists.
  7. The system creates a new account with active status and a Coin wallet.
  8. The system creates a user session.
  9. The system redirects Guest to the home page.
Alternative Flows:

A.4.1 Alt Authorization Denied

  1. Guest denies authorization on the Google consent screen.
  2. The system receives a rejection response from Google.
  3. The system displays an error message indicating login was cancelled.
  4. Back to step 1.

A.6.1 Alt Account Already Exists

  1. The system verifies that an account with this Google ID already exists.
  2. The system updates the profile data if necessary.
  3. The system skips step 7 and proceeds to step 8.
Exceptions:

EX-5 OAuth2 Communication Error

  1. The system encounters a network error while communicating with Google servers.
  2. The system displays a system error message.
  3. Back to step 1.
Priority: High
Frequency of Use: Medium
Business Rules: None
Other Information: None
Assumptions:
  • Guest has stable internet connection.
