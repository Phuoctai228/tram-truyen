Functional Description Template

UC ID and Name:UC-10 Configure Chapter
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database
Trigger:Actor opens the configuration of an existing chapter.
Description:Sets draft or published state, VIP classification, and Coin price for a chapter.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The chapter exists and is not deleted.

Postconditions:

POST-1. The chapter publication and pricing configuration is stored.

Normal Flow:

A. Configure Chapter Successfully

  1. Actor accesses the chapter configuration form.
  2. The system retrieves the current configuration.
  3. Actor selects the publication status.
  4. Actor selects the VIP setting.
  5. Actor enters the Coin price when required.
  6. Actor submits the configuration using "Save".
  7. The system validates the configuration.
  8. The system stores the configuration.
  9. The system displays the updated chapter state.
Alternative Flows:

A.7 Invalid Configuration

  1. The system identifies an invalid status or price.
  2. The system displays validation guidance.
  3. Back to step 3.

A.6 Cancel Configuration

  1. Actor cancels the operation.
  2. The system keeps the previous configuration.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-8 Database Failure

  1. The system fails to store the configuration.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Frequent
Business Rules:
  • Only Staff and Admin may configure chapters.
  • A VIP chapter must have a positive Coin price.
  • A regular published chapter does not require a Coin price.
Other Information:A chapter must be configured as published before it is available to readers.
Assumptions:
  • Staff and Admin have a stable internet connection.
