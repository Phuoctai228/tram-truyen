Functional Description Template

UC ID and Name:UC-06 Create Chapter
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database
Trigger:Actor chooses to add a chapter to a novel.
Description:Creates a chapter with a title, sequence number, and text content.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The target novel exists and is not deleted.

Postconditions:

POST-1. A chapter is stored under the selected novel.

Normal Flow:

A. Create Chapter Successfully

  1. Actor accesses the chapter creation form.
  2. Actor enters the chapter information.
  3. Actor submits the form using "Create".
  4. The system validates the information.
  5. The system creates the chapter record.
  6. The system displays the chapter in the novel contents.
Alternative Flows:

A.4 Invalid Information

  1. The system identifies invalid information.
  2. The system displays validation guidance.
  3. Back to step 2.

A.2 Cancel Creation

  1. Actor cancels the operation.
  2. The system returns to the chapter list.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-5 Database Failure

  1. The system cannot save the chapter.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Frequent
Business Rules:
  • Only Staff and Admin may create chapters.
  • Chapter sequence numbers must be unique within a novel.
Other Information:A newly created chapter follows the configured initial status.
Assumptions:
  • Staff and Admin have a stable internet connection.
