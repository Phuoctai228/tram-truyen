Functional Description Template

UC ID and Name:UC-03 Archive Novel
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database
Trigger:Actor chooses to temporarily hide a novel.
Description:Changes an active novel to an archived state so it is hidden from public browsing.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The novel exists and is active.

Postconditions:

POST-1. The novel has archived status.

POST-2. The novel is excluded from public browsing.

Normal Flow:

A. Archive Novel Successfully

  1. Actor accesses the internal novel list.
  2. Actor selects a novel.
  3. Actor selects "Archive".
  4. The system requests confirmation.
  5. Actor confirms the operation.
  6. The system updates the novel status.
  7. The system displays the updated list.
Alternative Flows:

A.5 Cancel Archive

  1. Actor cancels the confirmation.
  2. The system keeps the current status.
  3. Back to step 2.

A.2 Novel Already Archived

  1. The system identifies the archived status.
  2. The system displays the current status.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-6 Database Failure

  1. The system cannot update the status.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Occasional
Business Rules:
  • Only Staff and Admin may archive novels.
  • Archived novels must not appear in public lists.
Other Information:Archiving does not delete novel data or chapters.
Assumptions:
  • Staff and Admin have a stable internet connection.
