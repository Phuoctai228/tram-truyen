Functional Description Template

UC ID and Name:UC-02 Update Novel
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database, Cloudinary
Trigger:Actor selects an existing novel for editing.
Description:Allows authorized staff to update novel information, release status, and cover image.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The novel exists and is not deleted.

Postconditions:

POST-1. The novel information is updated.

Normal Flow:

A. Update Novel Successfully

  1. Actor accesses the novel edit form.
  2. The system retrieves the novel information.
  3. Actor changes the novel information.
  4. Actor submits the form using "Save".
  5. The system validates the submitted information.
  6. The system uploads a replacement cover when provided.
  7. The system updates the novel record.
  8. The system displays the updated novel.
Alternative Flows:

A.5 Invalid Information

  1. The system identifies invalid information.
  2. The system displays validation guidance.
  3. Back to step 3.

A.2 Novel Not Available

  1. The system cannot find the selected novel.
  2. The system displays an availability message.
  3. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-7 Update Failure

  1. The system fails to update the novel.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Frequent
Business Rules:BR-03
Other Information:Existing content remains unchanged when no replacement value is supplied.
Assumptions:
  • Staff and Admin have a stable internet connection.
