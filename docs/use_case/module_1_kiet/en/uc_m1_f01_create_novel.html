Functional Description Template

UC ID and Name:UC-01 Create Novel
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database, Cloudinary
Trigger:Actor selects the option to create a novel.
Description:Allows authorized staff to initialize a novel with its title, original author, summary, and cover information.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The system is connected to the database.

Postconditions:

POST-1. A new novel record is stored.

POST-2. The system displays the created novel.

Normal Flow:

A. Create Novel Successfully

  1. Actor accesses the novel creation form.
  2. Actor enters the novel information.
  3. Actor submits the form using "Create".
  4. The system validates the submitted information.
  5. The system uploads the cover image when provided.
  6. The system creates the novel record.
  7. The system displays a successful creation result.
Alternative Flows:

A.4 Invalid Information

  1. The system identifies invalid or incomplete information.
  2. The system displays validation guidance.
  3. Back to step 2.

A.2 Cancel Creation

  1. Actor cancels the operation.
  2. The system returns to the novel list.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-5 Storage Failure

  1. The system cannot store the novel or cover.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Occasional
Business Rules:BR-02, BR-03
Other Information:The cover image is stored through the configured media service.
Assumptions:
  • Staff and Admin have a stable internet connection.
