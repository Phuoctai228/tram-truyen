UC ID and Name:UC-08 Lock Unlock Chapter
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database
Trigger:Actor chooses to lock or unlock a chapter.
Description:Temporarily hides or restores a chapter in the public contents.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The chapter exists and is not deleted.

Postconditions:

POST-1. The chapter has the selected lock state.

Normal Flow:

A. Lock or Unlock Chapter Successfully

  1. Actor accesses the chapter management list.
  2. Actor selects a chapter.
  3. Actor selects "Lock" or "Unlock".
  4. The system requests confirmation.
  5. Actor confirms the operation.
  6. The system updates the chapter status.
  7. The system displays the updated chapter list.
Alternative Flows:

A.5 Cancel Status Change

  1. Actor cancels the confirmation.
  2. The system keeps the current status.
  3. Back to step 2.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-6 Database Failure

  1. The system cannot update the status.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Occasional
Business Rules:
  • Only Staff and Admin may change chapter lock state.
  • A locked chapter is unavailable for public reading.
Other Information:Locking does not delete chapter content.
Assumptions:
  • Staff and Admin have a stable internet connection.
