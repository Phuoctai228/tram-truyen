Functional Description Template

UC ID and Name:UC-07 Update Chapter
Created By:Lai Le Tuan KietDate Created:2026-09-22
Primary Actor:Staff, AdminSecondary Actors:Database
Trigger:Actor selects an existing chapter for editing.
Description:Updates the title, sequence number, or text content of an existing chapter.
Preconditions:

PRE-1. Staff or Admin is authenticated and authorized.

PRE-2. The chapter exists and is not deleted.

Postconditions:

POST-1. The chapter information is updated.

Normal Flow:

A. Update Chapter Successfully

  1. Actor accesses the chapter edit form.
  2. The system retrieves the chapter information.
  3. Actor changes the chapter information.
  4. Actor submits the form using "Save".
  5. The system validates the information.
  6. The system updates the chapter record.
  7. The system displays the updated chapter.
Alternative Flows:

A.5 Invalid Information

  1. The system identifies invalid information.
  2. The system displays validation guidance.
  3. Back to step 3.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system displays an authentication error message.
  2. The system redirects the user to the login page.

EX-6 Update Failure

  1. The system fails to update the chapter.
  2. The system displays a temporary failure message.
Priority:High, Must Have
Frequency of Use:Frequent
Business Rules:
  • Only Staff and Admin may update chapters.
  • Chapter sequence numbers must remain unique within a novel.
Other Information:Updating a chapter does not change its publication configuration unless explicitly changed.
Assumptions:
  • Staff and Admin have a stable internet connection.
