Functional Description Template

UC ID and Name: UC-10 Update Profile
Created By: Nguyễn Ngọc Date Created: 2026-09-19
Primary Actor: Member, Staff, Admin Secondary Actors: Cloudinary Image Service
Trigger: Actor clicks the "Edit Profile" button on their profile page.
Description: Allows the user to modify their personal information, such as their username and avatar. Avatar images are processed and uploaded to the Cloudinary CDN.
Preconditions:

PRE-1. The actor is currently authenticated.

PRE-2. The integration with the Cloudinary service is properly configured and operational.
Postconditions:

POST-1. The user's profile information is updated in the database and the new avatar URL is stored.
Normal Flow:

A. Update Profile Successfully

  1. Actor accesses the Edit Profile form.
  2. The system pre-fills the form with the user's current data (Username, Avatar preview).
  3. Actor modifies the Username and/or selects a new image file for the avatar.
  4. Actor submits the form.
  5. The system validates the input (e.g., username length/uniqueness, image file size/format).
  6. The system streams the image file to the Cloudinary API.
  7. Cloudinary processes the image and returns a secure URL.
  8. The system updates the user record in the database with the new Username and the new Cloudinary URL.
  9. The system refreshes the user's session data to reflect the changes immediately.
  10. The system redirects the actor back to the View Profile page (UC-08) and displays a success notification.
Alternative Flows:

A.5 Alt Username Taken

  1. The system determines the requested username is already in use by another account.
  2. The system displays an error message: "Username is already taken."
  3. Back to step 3.

A.5 Alt Invalid File

  1. The system determines the uploaded file exceeds the maximum size limit (e.g., 2MB) or is not a supported format (JPG/PNG).
  2. The system displays an error message explaining the constraints.
  3. Back to step 3.
Exceptions:

EX-6 Cloudinary Upload Failure

  1. The system fails to upload the image to Cloudinary (e.g., network timeout, bad credentials).
  2. The system rolls back any pending database changes.
  3. The system displays an error message: "Failed to upload image. Please try again later."
Priority: Medium, Should Have
Frequency of Use: Low
Business Rules:
  • Users cannot change their registered Email address through this interface.
  • Uploaded avatars must be cropped to a 1:1 square aspect ratio via Cloudinary transformations before saving.
Other Information: None
Assumptions:
  • Actor has a stable internet connection for uploading files.
