UC ID and Name: UC-05 Logout
Created By: Nguyễn Ngọc Date Created: 2026-09-19
Primary Actor: Member, Staff, Admin Secondary Actors: None
Trigger: Actor clicks the "Logout" link/button in the user profile dropdown menu.
Description: Safely terminates the actor's current active session and clears any persistent login cookies, converting them back to a Guest.
Preconditions:

PRE-1. The actor is currently authenticated with an active session.
Postconditions:

POST-1. The actor's session is invalidated and they revert to Guest status.
Normal Flow:

A. Logout Successfully

  1. Actor clicks the "Logout" button.
  2. The system receives the logout request.
  3. The system invalidates the server-side session object.
  4. The system clears the authentication context.
  5. The system instructs the browser to delete any session cookies and "Remember-Me" tokens.
  6. The system redirects the actor to the public homepage or login page.
Alternative Flows:

None
Exceptions:

None
Priority: High, Must Have
Frequency of Use: High
Business Rules:
  • Session invalidation must be absolute (not just clearing client-side cookies) to prevent session hijacking.
Other Information: None
Assumptions:
  • None
