UC ID and Name: UC-09 View Coin History
Created By: Nguyễn Ngọc Date Created: 2026-09-19
Primary Actor: Member, Staff, Admin Secondary Actors: None
Trigger: Actor navigates to the "Transaction History" tab in their profile.
Description: Displays a paginated audit log of all Coin transactions (both top-ups and expenditures like chapter unlocks or daily check-ins) associated with the actor's wallet.
Preconditions:

PRE-1. The actor is currently authenticated.
Postconditions:

POST-1. The actor views their financial transaction records.
Normal Flow:

A. View History Successfully

  1. Actor clicks the "Transaction History" tab.
  2. The system validates the session.
  3. The system queries the database for transaction logs belonging to the user's wallet ID, ordered by date descending.
  4. The system applies pagination logic (e.g., limit 20 items per page).
  5. The system formats the transaction amounts (showing + for income, - for expenses).
  6. The system renders the data in a table format (Date, Type, Amount, Description).
Alternative Flows:

A.3 Alt Empty History

  1. The system determines there are no transaction logs for the user.
  2. The system renders a "No transactions found" message.
  3. Back to step 1.

A.4 Alt Page Navigation

  1. Actor clicks a pagination control (e.g., "Next Page").
  2. The system executes the query with the corresponding offset.
  3. The system updates the table view.
  4. Back to step 1.
Exceptions:

EX-1 Session Invalid (Not Logged In)

  1. The system determines the actor is not logged in.
  2. The system redirects the user to the login page.
Priority: Medium, Should Have
Frequency of Use: Low
Business Rules:
  • Transaction history is immutable; neither the user nor an Admin can manually delete these audit logs.
Other Information: None
Assumptions:
  • None
