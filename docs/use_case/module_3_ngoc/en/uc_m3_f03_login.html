UC ID and Name: UC-03 Login
Created By: Nguyễn Ngọc Date Created: 2026-09-19
Primary Actor: Guest Secondary Actors: None
Trigger: Actor clicks the "Login" button and submits the authentication form.
Description: Authenticates a user into the system using their email and password. Supports Remember-Me functionality and checks account validity before creating a session.
Preconditions:

PRE-1. The actor is not currently authenticated.
Postconditions:

POST-1. A secure session is created and the actor is authenticated as their respective role.
Normal Flow:

A. Login Successfully

  1. Actor accesses the login page/modal.
  2. Actor enters their Email and Password, optionally checking "Remember Me", and submits.
  3. The system retrieves the user record associated with the provided email.
  4. The system verifies the provided password against the BCrypt hashed password in the database.
  5. The system checks the user's USER_STATUS to ensure they are ACTIVE.
  6. The system initializes a secure user session (and generates a persistent token if "Remember Me" is checked).
  7. The system redirects the user to the homepage (or the previous page they attempted to access).
Alternative Flows:

A.3 Alt Invalid Credentials

  1. The system determines the email does not exist or the password does not match.
  2. The system displays a generic error message: "Invalid email or password."
  3. Back to step 2.

A.5 Alt Account Pending

  1. The system determines the user's status is PENDING_VERIFICATION.
  2. The system displays an error message and a link to the verification page.
  3. Back to step 2.

A.5 Alt Account Banned

  1. The system determines the user's status is BANNED.
  2. The system displays an error message indicating the account is suspended.
  3. Back to step 2.
Exceptions:

None
Priority: Critical, Must Have
Frequency of Use: Very High
Business Rules:
  • For security against enumeration attacks, the error message for an incorrect email must be identical to the error for an incorrect password.
Other Information: None
Assumptions:
  • Actor has a stable internet connection.
