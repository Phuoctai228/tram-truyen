Kích hoạt Giọng đọc Tiếng Việt

Hướng dẫn cài đặt giọng đọc AI tự nhiên cho thiết bị của bạn

1
Nhấn tổ hợp phím Windows + I để mở Cài đặt (Settings).
2
Vào mục Time & Language (Thời gian & Ngôn ngữ) → chọn Language & region.
3
Nhấn Add a language → Tìm kiếm và chọn Tiếng Việt (Vietnamese).
4
Quan trọng: Tích chọn ô "Text-to-speech" (Chuyển văn bản thành giọng nói) rồi bấm Install.
5
Sau khi tải xong, khởi động lại trình duyệt và tải lại trang. Hệ thống sẽ có giọng Microsoft HoaiMy / An tự nhiên.
recommend Khuyên dùng Microsoft Edge:

Trình duyệt Edge tích hợp sẵn bộ giọng đọc trực tuyến Microsoft Natural tiếng Việt đọc rất mượt mà mà không bắt buộc cài thêm gói ngôn ngữ hệ thống.

language Trên Google Chrome / Cốc Cốc:

Mở Cài đặt trình duyệt → Ngôn ngữ → Thêm Tiếng Việt làm ngôn ngữ ưu tiên hàng đầu để Chrome kích hoạt giọng đọc tiếng Việt của Google.

android Android:

Hệ điều hành Android đã có sẵn Google TTS tiếng Việt. Bạn có thể mở web đọc bằng Chrome trên điện thoại để nghe ngay.

phone_iphone iPhone / iPad (iOS 16 trở lên):

Vào Cài đặt → Trợ năng → Đọc nội dung → Giọng nói → Tiếng Việt → Tải gói giọng nói (Linh).
